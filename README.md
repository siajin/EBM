# EBM 오디오 딥페이크 탐지 연구

이 저장소는 **Enhanced Bona fide Modeling(EBM)** 원본 구현을 바탕으로 진행한 모델 학습과 가설별 실험을 정리한다. 동결된 XLS-R의 다층 특징을 bridge·attention·통계 pooling으로 결합하고, linear·LayerNorm을 거쳐 160차원 임베딩을 만든다. 임베딩과 학습된 정상 중심의 코사인이 높을수록 정상 음성으로 판단한다.

학습에는 **클래스 가중 OCSoftmax 분류 손실**과 **정상 음성 쌍 학습(Bonafide-Pair Learning, BPL)**을 사용한다. 정상 쌍 학습은 같은 발화의 긴·짧은 입력뿐 아니라, 배치 안의 서로 다른 정상 발화 사이의 전체 교차쌍도 정렬한다. 한 논리 배치에서 backend를 먼저 갱신하고, 갱신된 backend의 정상 출력으로 OC 중심을 갱신한다. 이 중심은 정상 임베딩의 단순 산술평균과 다르다.

문서에서는 실험의 입력 방식과 변경 목적이 드러나는 이름을 사용한다. 학습 당시의 파일명·브랜치명은 코드와 기록을 정확히 찾을 수 있도록 링크 목적지에 유지했다. [용어와 입력 길이 안내](experience/TERMINOLOGY.md)

### 고정 길이 반복 입력 학습: 비교 기준을 보존하기 위한 복원

긴 입력은 64,600샘플(4.0375초), 짧은 입력은 48,440샘플(3.0275초)이다. 원음이 목표보다 짧으면 순환 반복하고, 길면 긴 입력은 앞부분·짧은 입력은 연속 무작위 구간을 사용한다. 두 입력에는 독립 RawBoost를 적용한다. 클래스별 DataLoader와 DistributedSampler, 작은 정상 로더의 순환, 전체 연산 그래프와 두 단계 Adam을 사용한다.

복원 브랜치의 목적은 이후 변경을 비교할 기준 코드를 확보하는 것이다. **복원 과정에서는 코덱 변형을 껐지만, 과거 저장 모델을 학습할 때 실제 코덱이 적용됐는지는 확정하지 못했다.** 따라서 과거 성능을 코덱 비활성 재학습의 성능으로 바꿔 제시하지 않는다. 재학습 준비 브랜치는 이 복원 코드에서 Python 설정의 결과 이름만 바꿨으며, 해당 재학습을 실행한 결과는 없다. [고정 길이 반복 입력 학습 기록](experience/02_repetition/E005/README.md)

### 4.0375초 상한 비반복 학습: 반복 문맥 의존을 줄일 수 있는가?

**가설:** 짧은 원음을 목표 길이까지 반복하면 반복량·접합·frontend 문맥이 추가된다. 모델이 이런 처리에 의존한다면, 원래 길이를 유지하는 학습이 다른 길이와 도메인에 더 잘 일반화할 가능성이 있다.

이 가설을 살피기 위해 긴·짧은 입력의 **상한은 각각 64,600·48,440샘플로 유지하고 순환 반복을 제거**했다. 더 짧은 원음은 실제 길이 그대로 사용한다. 서로 다른 길이의 입력을 배치로 처리할 때만 오른쪽에 0을 붙이고, XLS-R과 각 시간 pooling에 유효 길이 마스크를 전달한다. 따라서 입력의 0 채움을 음성 정보로 집계하지 않게 했다.

가변 길이의 논리 배치를 메모리 안에서 처리하기 위해 길이를 고려한 클래스 균형 샘플러와 물리 배치 8의 분할 계산·기울기 재계산을 사용했다. 원래 긴 입력 OC와 정상 긴×짧은 전체쌍 손실, backend→중심의 두 단계 갱신을 유지했으며 짧은 입력 분류 손실이나 반복 관련 보조 손실은 추가하지 않았다. 전체 배치 240, seed 1, 학습률 1e-5, 50epoch, 동결 XLS-R, RawBoost·코덱 비활성을 사용했다.

과거 고정 길이 반복 입력 모델보다 **같은 비반복 평가 입력에서는** 세 집합 EER이 낮았다. 다만 과거 모델과는 반복뿐 아니라 샘플러·마스크·계산 방식도 달라졌다. 이 비교만으로 반복 제거의 단독 인과 효과를 확정할 수는 없다. [상세 가설·변경·결과](experience/02_repetition/E006/README.md)

### 원음 전체 비반복 학습: 긴 발화의 내용을 더 보존하면 도움이 되는가?

**가설:** 반복을 제거해도 긴 입력을 앞 4.0375초로 자르면 그 뒤의 발화 내용이 사라진다. 원음 전체의 더 긴 문맥을 학습하면 표현과 일반화가 개선될 가능성이 있다.

이를 확인하려고 **직전 비반복 학습의 긴 입력 상한만 제거**했다. `arguments.py`에서 학습용 `cap_long=False`를 설정했다. 짧은 입력은 최대 48,440샘플의 연속 무작위 구간을 유지하고, 짧은 원음은 계속 반복하지 않는다. 모델·손실·샘플러·optimizer·기울기 재계산 코드는 직전 비반복 학습과 같다. 학습된 가중치를 이어 쓰지 않고 seed 1의 초기화에서 다시 학습했다.

학습과 평가 문맥이 동시에 바뀌지 않도록 `data_loaders.py`의 **평가용 로더에는 `cap_long=True`를 명시**했다. 따라서 두 비반복 학습 모델의 평가는 모두 앞 64,600샘플 상한·비반복·마스크를 사용한다. 두 브랜치의 실제 실행 코드 차이는 실험 이름·학습 상한과 이 평가 상한 분리다.

고정 50epoch 비교에서 2019 LA는 개선됐지만 2021 LA와 DeepFake는 악화했다. **더 긴 학습 문맥이 모든 도메인에 일관되게 유리하다는 가설은 지지되지 않았다.** 한 seed의 결과이며, 입력 길이가 달라지면 내용·증강 실현값·난수 소비도 달라질 수 있다. [상세 가설·변경·결과](experience/01_duration_bias/E007/README.md)
