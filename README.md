# EBM 오디오 딥페이크 탐지 연구

이 저장소는 **Enhanced Bona fide Modeling (EBM)** 원본 구현을 바탕으로 진행한 학습과 가설별 실험을 보존한다. 동결 XLS-R의 다층 특징을 bridge·층 attention·통계 pooling·linear·LayerNorm으로 160차원 임베딩에 모으고, 학습한 정상 중심과의 코사인으로 정상과 위조를 구분한다.

원래 목적식은 클래스 가중 OC와 정상 long×short **전체 교차쌍 BPL**이다. 같은 발화의 대각 쌍과 다른 발화 사이의 쌍을 모두 포함한다. 한 논리 배치에서 backend를 OC+BPL로 갱신한 후, 갱신된 backend의 정상 출력만으로 중심을 갱신한다. 학습된 OC 중심은 단순 정상 평균과 다르다. 상세 수식과 후속 역할 전환은 [설계서](experience/_shared/references/docs/experiments/ebm_spoof_centered_design_20261112.md)에 있다.

3. [정상 다양성·도메인 지지와 정상쌍 학습](experience/03_bonafide_diversity/README.md) — 새 도메인 EER 악화가 위조 변화보다 정상 지지의 이동에 민감하고, 정상 다양성 확대가 해결의 단서인가?
4. [코사인 외 norm과 정규화 전 통계](experience/04_norm_information/README.md) — 코사인이 같은 경우에도 norm·정규화 전 평균·스케일이 판별 신호를 갖는가?
5. [잔여 방향·좌표·거리·기하와 변형 반응](experience/05_residual_geometry/README.md) — 단일 정상 중심과의 각도 밖에 판별 신호가 남고, 이를 읽거나 조절해 전이 성능을 높일 수 있는가?
6. [스푸프 중심 EBM의 역할 전환](experience/06_spoof_centered/README.md) — 정상 대신 알려진 위조를 한 중심과 전체쌍 BPL로 모으고 정상을 밀어내면 일반화에 도움이 되는가?


각 실험 폴더의 README에는 **가설·설계 이유·상세 절차·결과·해석과 실패·배운 점·실제 코드·검산 근거**를 담았다. 기존 110개와 최근 3개 후속 기록을 모두 수록했다. 같은 학습의 여러 평가·분석도 포함하므로 113회 독립 학습을 의미하지 않는다. [전체 113개 기록](experience/README.md) · [코드와 재현](experience/REPRODUCIBILITY.md) · [출처 검증](experience/SOURCE_COVERAGE.md)

## 최종 결과 요약

|확정 결과|19LA EER|21LA EER|DF EER|
|---|---:|---:|---:|
|기존240 50epoch: 공통 비반복 평가|1.128484%|6.688715%|8.877530%|
|B50: 반복 제거·long 상한|0.679810%|4.792117%|2.723788%|
|C50: 반복 제거·long 전체|0.584636%|5.163467%|2.881368%|
|길이·VAD·전수 노출 복합 20epoch|2.708118%|8.908218%|2.286637%|
|short32 지정 25epoch|1.210061%|11.308488%|5.427399%|

위 표는 같은 비반복 기본 입력을 사용한 지정 checkpoint 결과이며, 학습 epoch와 실행 난수는 행마다 다르다. B/C의 10개 저장점에서 얻은 사후 최소는 각각 **19LA 0.462271/0.488400%, 21LA 3.759449/4.622076%, DF 2.084875/2.152549%**다. 집합별 최적 epoch가 달라 단일 모델의 성능으로 합치지 않는다.

반복의 영향은 모델에 따라 반대였다. 길이 균형·short32 학습의 일반화 개선은 확립되지 않았고, 벡터 방향의 내부 판독 이득도 독립 전이 개선으로 연결되지 않았다. 역방향 EBM은 로컬 구현·86개 검사까지 완료했으며 실제 GPU 학습 EER은 없다. 실패·취소·미실행 항목도 각 문서에 보존했다. [전체 비교·같은 25epoch 대조·과거 반복 평가와의 차이](experience/RESULTS.md)
