# E106. 앞 저에너지 100ms 이하·500ms 이상인 자연 표본의 양 클래스 평가

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

자연적으로앞구간이 짧거나긴 집단에서 분리력이 다를 수 있다.

## 그렇게 설계한 이유

짧고 긴 자연 앞 구간에서 분리력이 어떻게 다른지 조사한다.

대조와 통제의 근거: 서로 다른 파일·공격의 구성 비교다. 앞 길이를 바꾼 동일 음성 개입이 아니며 전체 평가 정답으로 고른 임계값은 독립 개발 보정이 아니다.

## 모델·데이터·표본

[E105](../E105/README.md)의 동일 ASV 원음 전체 점수. VCC·새 학습·새 음성 추론 없음.

## 실험 내용과 상세 절차

1. [E105](../E105/README.md)의 −20dB 앞 길이를 정수 프레임으로 세어 5프레임 이하(100ms 포함)와 25프레임 이상(500ms 포함)을 고른다.
2. 각 집단에 정상·위조를 모두 포함해 선형 보간 EER·AUROC를 계산한다. 가장 가까운 실제 ROC 운영점 오류도 별도로 기록한다.
3. 전체 ASV 1,298개에서 |위조 통과율−정상 거부율| 최소의 사후 임계값 0.983722806을 정해 두 집단에 그대로 적용한다.
4. 집단 안 화자를 양 클래스 함께 2,000회 재표집하고 한 클래스가 빠지는 반복을 제외·기록한다. 공격별 공통 표본 지원을 조사한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

100ms 이하 정상 5개·위조 155개의 EER은 0%, 500ms 이상 정상 1,036개·위조 63개는 약 0.772%였다. 짧은 쪽 정상은 3명뿐이고 두 극단의 위조 공격이 겹치지 않아 길이의 독립 효과를 판정하지 못했다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

짧은집단의0%EER은 정상5개·3명뿐이다. 공격구성이달라 인과적길이효과나 일반적우위를 주장할 수 없다.
