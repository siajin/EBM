# 원음 전체와 실제 긴·짧은 증강 입력의 저에너지 위치 분포 전수 조사

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

원음의저에너지차이는 실제crop·반복·codec·RawBoost뒤에도 형태를바꾸어 남을 수 있다.

## 그렇게 설계한 이유

클래스별 저에너지 차이가 실제 입력 생성 뒤에도 어떤 형태로 남는지 측정한다.

대조와 통제의 근거: 이 진단의 코덱 호출은 과거 저장 모델 학습의 실제 코덱 횟수를 증명하지 않는다. 정상만 원래 BPL에 쓰이며 위조 입력은 비교용으로 생성했다. DF는 ASV 출처만 포함한다.

## 모델·데이터·표본

학습·개발 전수와 ASV 계열 평가 표본. 기존 TrainSet 동등 입력 생성만 실행했으며 탐지기 점수·새 학습은 없다.

## 실험 내용과 상세 절차

1. 2019 LA 학습 25,380개·개발 24,844개 전체와 19LA 평가·21LA·DF ASV 출처 각 클래스 1,000개를 사용한다. 원음 총 56,224개다.
2. 원음의 20ms 비중첩 RMS를 측정한다. 마지막 부분 프레임은 실제 샘플 수로 계산하고 자기 최대 RMS의 10%/1%보다 작은 구간을 −20/−40dB 저에너지로 정의한다.
3. 앞·뒤·내부·전체 길이와 비율, 내부 연속 구간 수·최장 길이, 정확한 0 비율, 최고 RMS·저에너지 에너지 비율, 20개 시간 위치 구간의 프로파일을 만든다.
4. 학습 정상 전체 2,580개와 같은 수의 위조를 뽑고 원음마다 두 개의 seed 고정 실제 입력 추출을 만들어 10,320개 기록을 얻는다. 긴·짧은 입력을 각각 조사한다.
5. 무증강 절단·반복 참조, 실제 코덱 뒤 RawBoost 전, 최종 자기 상대 문턱, RawBoost 전 문턱을 고정해 최종 파형에 적용한 네 단계를 비교한다.
6. 원본 구간 겹침·반복량·증강 유형·같은 파일 두 추출 간 차이·코덱으로 조용한 부분이 변하는 정도와 분모를 검산한다. 모델 추론·학습은 하지 않는다.

## 측정과 검증

원음·쌍 기록 개수, 정수 샘플 길이, 조건부 분모, 증강 단계별 문턱, 파일반복 추출과 소스 해시를 검증했다.

## 결과

완료 표식은 원음 56,224개·실제 입력 기록 10,320개·소스 불변을 기록했다. 상대 저에너지는 정답 무음이 아니며 두 추출로 모든 과거 epoch를 재구성하지 않았다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

원음과실제입력분포를 나눠야 한다. 두seed의입력재생이나진단codec호출로 과거전체학습을 복원했다고 주장할 수 없다.
