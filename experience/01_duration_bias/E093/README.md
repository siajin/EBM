# 학습 원음의 저에너지·음량 분포와 클래스 단서의 초기 조사

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

학습원음에도 클래스별 앞저에너지길이 차이가 있을 수 있다.

## 그렇게 설계한 이유

평가에서 본 저에너지 연관성이 학습 자료에도 있는지 확인한다.

대조와 통제의 근거: 학습 원본의 분포이며 모든 epoch의 실제 절단·코덱·RawBoost 입력 분포를 재현한 것은 아니다.

## 모델·데이터·표본

2019 LA 학습 정상·위조 각 1,000개, seed 17. 파형 통계만 계산하며 이 작업 자체의 탐지기 학습·추론은 없다.

## 실험 내용과 상세 절차

1. 2019 LA 학습 자료에서 seed 17로 정상·위조 각 1,000개를 고정한다.
2. 원음 길이, RMS dBFS, 최대 20ms RMS 대비 −20dB 프레임 비율, 앞·뒤 연속 저에너지 길이를 측정한다.
3. 각 단일 값의 클래스 순위 AUROC와 클래스별 평균·중앙값을 기술한다. 모델 가중치는 바꾸지 않는다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

앞 저에너지 길이 중앙값은 정상 1.00초·위조 0.48초였다. 전체 파일 길이 중앙값은 3.280844/3.227781초로 차이가 훨씬 작았다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

전체길이가비슷해도 앞구간분포는달랐다. 원음통계는 실제증강입력 전체분포를 대신하지 않는다.
