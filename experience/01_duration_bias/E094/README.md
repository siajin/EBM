# 저에너지 구간의 길이·에너지를 유지한 미세 파형 구조 개입

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

길이·에너지를유지해도 저에너지 내부질감이 점수를 움직일 수 있다.

## 그렇게 설계한 이유

저에너지 구간의 존재·길이 외에 그 안의 파형 모양에도 모델이 반응하는지 본다.

대조와 통제의 근거: 순서 섞기는 길이·위치·에너지가 같아도 시간·스펙트럼 모양을 바꾼다. 0 교체는 에너지를 보존하는 대조가 아니다.

## 모델·데이터·표본

배치 80·80epoch의 고정 모델(체크포인트 SHA256 30043199664bc84da780654e01fd430235f647b894e7832a52f777c7fee5939a). 별도 명시가 없으면 DF eval에서 seed 1로 정상·위조 각 1,000개를 클래스 안에서 중복 없이 무작위 추출한 같은 2,000개다. 추론 배치 4, worker 2, 원래 앞 64,600샘플·부족하면 순환 반복, 증강 없음이다.

## 실험 내용과 상세 절차

1. 원래 고정 입력의 최대 20ms RMS보다 40dB 작은 앞뒤 구간을 선택한다.
2. 기준, 선택 부분 0 교체, 20ms 프레임 안 샘플 순서 섞기, 프레임별 RMS가 같은 백색잡음 교체를 비교한다. 추가로 −20dB 선택 부분의 순서도 섞는다.
3. 선택되지 않은 샘플을 유지한다. 순서 섞기의 프레임 평균·히스토그램·에너지와 잡음 교체의 에너지 보존을 검사한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

정상 꼬리 수는 기준 163개, −40dB 부분 0/순서 섞기/잡음에서 186/191/191개, −20dB 순서 섞기에서 277개였다. 대응 표본 EER은 2.0/1.9/1.8/1.8/1.9%였다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

질감반응은있지만 꼬리수와EER방향은 달랐다. 에너지보존 대조와0교체를 구분해야 한다.
