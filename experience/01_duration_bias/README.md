# 길이·유효 발화량과 앞뒤 저에너지 편향

## 연구 질문과 설계 배경

클래스와 길이·음성활동·앞뒤 저에너지의 연결을 줄이면 미지 위조 일반화를 개선할 수 있는가?

분포 제어의 가능성과 점수 민감성은 확인했지만 학습 일반화 개선은 확립하지 못했다. 길이·음성활동·원음 전수 노출을 맞춘 20epoch 학습·짧은 정상 음성의 3.0275초·2초 정렬 학습의 악화와 속도 0.8~1.2배·최대 20% 절단 변형 실행 실패를 함께 보존한다.
