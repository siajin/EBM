# E102. ASVspoof 출처만 남긴 자연 길이·자체 파형·제공자 효과 재검토

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

모든출처를합친 평균반응이 ASV출처 안에서도 유지될 수 있다.

## 그렇게 설계한 이유

VCC를 합친 평균이 ASV 학습 출처의 반응까지 대표하는지 확인한다.

대조와 통제의 근거: 서로 다른 입력 범위·개입을 하나의 원인 기여율로 합치지 않는다. VCC 결과를 새로 일반화하지 않는다.

## 모델·데이터·표본

고정 80epoch 모델의 기존 ASVspoof 출처 결과만 재사용. 주 자연 입력 비교의 적합 정상 494개·위조 91개이며 비교별 적합 수를 따로 유지한다.

## 실험 내용과 상세 절차

1. 기존 원음 전체 개입에서 ASVspoof 수신자와 자체 앞 구간 적합 표본만 남긴다.
2. 각 0.25/0.5/1초의 0−원본, 자체 파형−원본, 자체 파형−0과 0.25→1초 용량 변화를 분해한다.
3. ASV 출처 제공자 실험과 고정 입력의 순서·위상·진폭 효과를 같은 출처 범위에서 다시 정리한다. 새 추론은 하지 않는다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

자체 앞 구간 적합 ASV 정상 494개의 1초 0 추가 평균은 −0.009645, 자체 파형 추가는 −0.006141이었다. 전체 출처 평균과 같은 방향이라고 가정할 수 없었다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

ASV만보면 자체·0추가평균이음수였다. 출처혼합 평균을각출처에 그대로 적용하면 안 된다.
