# 화자가 다른 정상 발화 정렬과 같은 원음의 보수적 길이 일관성 결합 안

**실행 상태:** 설계·메타데이터 가능성 점검만; 학습 미실행

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

화자다른 정상정렬과같은원음 길이일관성을 결합하면 다양성과강건성을 함께 다룰 수 있다.

## 그렇게 설계한 이유

원래 정상·위조 분류를 보존하면서 잡음·화자 변이와 길이 변이에 대한 두 정상 쌍 손실을 분리해 시험하는 대조 실험을 설계했다.

대조와 통제의 근거: 당시 이름 BPL1/BPL2는 이 두 항의 별칭이다. 같은 두 묶음의 입력 순서만 바꾸면 전체 교차 평균은 변하지 않으므로 선택 쌍·mask·별도 호출이 필요하다.

## 모델·데이터·표본

계획상 학습 자료 정상 2,580개·EBM-Repeat 구조. 실제 장기 학습·새 모듈 추론 결과는 없다.

## 실험 내용과 상세 절차

1. 화자별 항은 anchor와 같은 화자·다른 원음 ID를 고르고 입력 목표 길이 및 유효 원음 비 min/max ≥0.8로 맞춘다. 서로 다른 RawBoost·양방향 gradient·codec-off를 계획했다.
2. 같은 원음 길이 항은 고유 구간 U =min(N,64,600)에서 U ≥32,000이면 80~90%연속 구간, 더 짧으면 전체를 학생 입력으로 쓴다. 학생은 비반복·mask 이며긴참조는 gradient를 끊는다.
3. VAD 발화 프레임 80%보존은 추가 조건 제안일 뿐 전수 가능성 검증을 하지 않았다. 상대 없으면 추가 항만 건너뛰고 OC 원음은 보존한다.
4. 기존 144쌍, 같은 입력에서 anchor 당 1쌍 12쌍, 화자 항만 교체, 길이 항만 교체, 둘 다 교체의 5 군을 제안했다. 처음 5epoch 원래 BPL,6~10 전환, 이후 OC +0.75 화자 항 +0.25 길 이 항 계획이었다.

## 측정과 검증

정상 2,580개 중 2,579개가 길이/화자 조건 상대가 있고 상대 수 중앙값 77개 인 메타데이터 가능성만 확인했다.

## 결과

최적계수·성능 개선 수치는 없다. 이 설계 전체를 현재 3/2초 추가 항 학습으로 실행한 것이 아니다.

## 해석·실패한 부분·한계

같은 화자 양성 정렬이 화자 정보 제거와 같지 않다. stop-gradient도 공유 모델의 긴 입력 성능 보존을 보장하지 않는다.

## 배운 점

설계·가능성 검토만 했다. stop-gradient가 긴입력 성능보존을 보장하지 않으며 새EER은 없다.

## 실험 코드

이 항목은 설계/예시/기존 기록 분석이다. 별도 실행 구현을 확보하지 못했거나 애초 구현하지 않았다. 아래 설정·설계·검산 근거를 보존했으며 실행 코드를 새로 꾸며 넣지 않았다.

코드의 파일별 원본 위치·SHA256은 [원본 파일 위치와 해시 목록](code/source_manifest.json)에 있다. 공통 의존성과 실행 위치는 [재현 안내](../../REPRODUCIBILITY.md)를 따른다. 역사 snapshot은 당시 실패를 포함한 실제 버전이며 최신 수정 코드와 구분한다.
