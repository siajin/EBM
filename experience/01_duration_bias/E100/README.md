# 원음 전체를 보존하고 앞 또는 뒤에만 저에너지를 추가한 엄격 대조

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

원음을손실없이보존해도 앞저에너지를늘리면 일관되게 정상쪽으로 갈 수 있다.

## 그렇게 설계한 이유

본문 손실 없이 앞 저에너지 자체의 효과와 앞뒤 위치 차이를 나눈다.

대조와 통제의 근거: 앞−뒤가 양수라는 사실과 앞−원본도 정상 방향이라는 사실은 다르다. 새 파일도 같은 자료 출처이며 과거 모델 선택에 쓰인 DF라는 제한이 남는다.

## 모델·데이터·표본

고정 80epoch 모델. 이전 2,000+새 2,000개 원음 전체 입력. 새 표본 출처별 정상 525/246/229, 위조 124/351/525개. 실제 파일 길이를 유지하며 미니배치 0 채움도 하지 않는다.

## 실험 내용과 상세 절차

1. 이전 반복 탐색 파일 2,000개와 파일 ID가 겹치지 않는 새 2,000개를 미리 고른다. 출처·라벨 수는 이전 표본에 맞춘다.
2. 원음 전체 PCM을 절단·정규화·반복·패딩 없이 보존한다. 0 또는 원래 −40dB 앞 구간의 파형을 0.25/0.5/1초 추가한다.
3. 같은 추가 파형 q로 앞 [q,x]와 뒤 [x,q]를 만든다. 앞/뒤는 길이·샘플 집합·에너지가 같다. 원래 앞 구간이 없는 경우 자체 파형 조건에서 제외한다.
4. 주량은 새 파일의 1초 조건에서 앞−원본과 앞−뒤, 두 파형 종류×두 클래스의 8개 평균이다. 20,000회 출처 안 화자 군집 재표집과 8비교 동시 95% 구간을 사용한다.
5. 같은 입력 반복 오차로 epsilon=max(1e-4, 반복 최대 오차의 10배)를 정한다. 1초의 10ms 선형 접합 완화·낮은 접합 부분·평균/중앙값/방향 비율을 함께 검사한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

새 정상의 1초 0 추가에서 앞−원본 평균 +0.010258이지만 중앙값 −0.002642, 정상 방향 291/1,000이었다. 위조는 평균 −0.085854로 오히려 위조 방향이었다. 앞에 길게 붙이면 일관되게 정상으로 간다는 단순 가설은 성립하지 않았다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

평균·중앙값·방향비율이 달라 단순가설은성립하지 않았다. 앞−뒤와앞−원본은 다른질문이다.
