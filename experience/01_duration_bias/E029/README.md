# E029. 최대 20% 절단·0.8~1.2배 속도로 길이 분포를 맞출 수 있는 한계

**실행 상태:** 메타데이터 최적화 완료·음성 변형 아님

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

원음 선택 확률을 유지하는 제한적 crop·속도 변형만으로도 길이 분포의 큰 부분을 맞출 수 있다.

## 그렇게 설계한 이유

원음을 버리거나 선택 비중을 바꾸지 않고 두 클래스의 길이 분포를 얼마나 맞출 수 있는 지 계산한다.

대조와 통제의 근거: 분포 겹침 =클래스별 정규화 확률의 min 합 =1 −TV. 원음별 균등 확률은 유지한다. 각 자료의 정답 클래스를 사용한 가능성 분석이다.

## 모델·데이터·표본

[E028](../E028/README.md)의 803,565개 원음. 다섯 자료 분할은 각각 따로 최적화한다.

## 실험 내용과 상세 절차

1. 원음 길이 D, 절단 비 c ∈[0,0.2], 속도배율 v ∈[0.8,1.2]에서 출력 D(1 −c)/v의 범위 [2D/3,1.25D]를 만든다.
2. 두 원음의 허용 구간이 겹치면 같은 길이로 바꿀 수 있다고 보고, 클래스별 균등 원음 확률을 용량으로 하는 이분 최대 유량 매칭을 푼다.
3. 클래스 개수의 최소공배수 정수 용량을 사용해 부동소수점 유량 오차를 피하고 최대 유량 =최소 절단 증명서를 검사한다.
4. 절단만·속도만·둘 다의 최대 공통 질량을 계산한다. 매번 여러 길이로 확률적으로 변형할 수 있는 최적 안과 원음당 하나의 weighted-median 출력 길이를 주는 구체안을 구별한다.

## 측정과 검증

연속 길이의 정확 공통 질량,0.05/0.1/0.25초 bin 민감도·KS·Wasserstein·변형 한계 검증.

## 결과

학습 자료 최대겹침은 절단만 97.6748%, 속도만 99.7181%, 둘 다 99.9737%.21LA는 79.0896/92.7466/99.2847%.

## 해석·실패한 부분·한계

이 때는 파형을 만들지 않았다. 한 학습 자료 정책이 평가 자료에도 같은 겹침을 내거나 위조 단서를 보존한다는 결과가 아니다. 단일 버전 구성 안의 전역 최적성도 주장하지 않는다.

## 배운 점
