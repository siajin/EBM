# E098. 저에너지 파형의 에너지·스펙트럼·위치 요인과 진폭 용량 비교

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

저에너지의진폭·위상·순서·위치가 서로다른반응을 만들 수 있다.

## 그렇게 설계한 이유

앞뒤 구간의 효과를 순서·위상·진폭과 전체 파형 크기 효과로 나눠 조사한다.

대조와 통제의 근거: 개발 임계값 0.816285938과 의미 있는 이동의 epsilon 0.000121을 고정한다.

## 모델·데이터·표본

고정 80epoch 모델, 새 DF 정상·위조 각 1,000개, seed 7921. 진폭 후속 seed 62419. 앞선 2,000개와 같은 것으로 섞지 않는다.

## 실험 내용과 상세 절차

1. 새 파일 2,000개를 사용하되 이미 같은 자료에서 탐색한 후속임을 표시한다. 고정 64,600샘플 입력과 앞뒤 저에너지 위치를 유지한다.
2. 기준·무변형 반복, 앞/뒤/양쪽 0 교체, 앞/뒤/양쪽 프레임 내 순서 섞기, 양쪽 위상 무작위화, 저에너지 진폭 0.1배·10배, 전체 진폭 0.1배, 비반복 입력, 앞/뒤 0 추가의 15조건을 평가한다.
3. 위상 무작위화는 프레임 파워 스펙트럼·에너지·평균을 보존한다. 원래 구간 밖 샘플은 전체 진폭 대조 외에는 그대로 둔다.
4. 진폭 후속은 1/0.5/0.25/0.1배를 사용한다. 초기 0.1배 결과를 본 뒤 정한 탐색 용량 비교다. 앞·뒤 상호작용과 전체 평균뿐 아니라 중앙값·방향 비율을 기록한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

새 표본의 기준 EER은 1.8%, 전체 진폭 0.1배는 4.8%였다. 양쪽 순서 섞기는 1.9%이지만 고정 임계값의 균형 오류율은 기준 5.8→7.05%로 늘었다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

표본EER이유사해도 개발고정임계값 오류는달랐다. 후속진폭용량 비교는 탐색으로표시해야 한다.
