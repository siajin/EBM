# E088. 동일 음성의 다섯 시간 위치·두 길이 절단 평가

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

다른시간위치를보면 앞구간 하나의 낮은정상점수를 구제할 수 있다.

## 그렇게 설계한 이유

앞부분 한 구간의 점수가 다른 위치의 점수와 얼마나 달라지는지 확인한다.

대조와 통제의 근거: 서로 겹치는 다섯 구간은 독립 원음 다섯 개가 아니다. 0.9는 정상 학습 경계이며 보정된 분류 임계값이 아니다.

## 모델·데이터·표본

배치 80·80epoch의 고정 모델(체크포인트 SHA256 30043199664bc84da780654e01fd430235f647b894e7832a52f777c7fee5939a). 별도 명시가 없으면 DF eval에서 seed 1로 정상·위조 각 1,000개를 클래스 안에서 중복 없이 무작위 추출한 같은 2,000개다. 추론 배치 4, worker 2, 원래 앞 64,600샘플·부족하면 순환 반복, 증강 없음이다.

## 실험 내용과 상세 절차

1. 64,600·48,440샘플 각각에서 가능한 시작점 범위의 0/25/50/75/100% 위치를 고정한다.
2. 같은 길이의 다섯 점수 범위와 0.9·0.2 학습 경계를 가로지르는 횟수를 계산한다. 이동할 여지가 없는 짧은 원음은 위치 범위 비교에서 제외한다.
3. 긴·짧은 앞구간은 한 번 더 계산해 추론 잡음과 기준 점수 재현 오차를 측정한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

긴 구간의 위치 이동이 가능한 정상 275개의 평균 점수 범위는 0.146596, 위조 222개는 0.035301이었다. 앞 점수가 0.9 미만인 정상 중 이동 가능 35개에서 3개만 다른 긴 구간이 0.9 이상이었다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

대부분의꼬리가 다른위치만으로 해결되지는 않았다. 겹치는crop을 독립음성으로 세지 않는다.
