# EBM 변형 반응 후보 재검토와 후속 실험 결정

작성: 2026-11-06 KST. 기존 캐시의 로컬 CPU 재분석과 후속 설계다. 새 음성 추론·EBM/분류기 학습·SSH는 실행하지 않았다. 서버의 현재 상태를 확인했다는 뜻이 아니다. 취소한 DF 4×3 CV는 실행·예약하지 않았다.

**결론: 확정된 ‘정상 유지 / 스푸프 정상 방향 이동’ 변형은 없다. 사용자의 후속 지시에 따라 주실험을 ‘원점수가 비슷한 정상·스푸프의 차등 반응’으로 정정한다. 먼저 같은 점수에서의 반응을 확인하고, 전체 전이 분류기 성능은 그다음 실용성 검증으로 둔다. layer attention 균등화와 짧은 무반복 crop은 이 주실험에 넣을 후보이지, 전체 평균 격차만으로 우선순위가 확정된 성공 방법이 아니다.**

이 결론은 후보의 부재를 증명하지 않는다. 아래 두 성격을 구분한다.

- **형태 가설:** 같은 변형에서 정상은 유지되고 스푸프는 정상 쪽으로 이동한다.
- **정보 가설:** 반응이 기존 점수·관측 조건을 넘어 탐지에 도움을 준다. 형태 가설이 실패해도 정보 가설은 별도로 시험할 수 있다.

## 0. 사용자 정정 반영: 실험의 중심과 순서

**원점수 겹침 표본 확보 실행 완료:** [전체 캐시·반응 coverage 확인 결과](ebm_full_score_overlap_results_20261106.md). 전체 native에서 엄격 최대 matching은 DF515/21LA106쌍이지만, 기존 변형 결과만으로 가능한 엄격 비교는6/3쌍이다. DF515쌍도18화자에한정된다. v2 결과는 최대쌍수 내 원점수차이의합을최소화했고, 기존반응의조건부점추정은여전히작은표본이다. 새GPU추론·fit은없다. 따라서정상·위조의 변형 반응 비교의확대검증을완료했다고해석하지않는다.

**주질문은 ‘같은 native score와 비교 가능한 녹음 조건에서, 정상·스푸프의 변형 반응 분포가 다른가?’다.** 전체 두 클래스 평균 이동량이나 전체 EER가 좋아지는지만 먼저 보는 것은 이 질문을 직접 검증하지 않는다. 아래 원점수 겹침 표본 확보→정상·위조의 변형 반응 비교을 주실험으로 하며, 기존4절의 readout 전이는 변형 반응 판독기의 전이 평가 보조 단계다. 이 절의 순서가 뒤의 과거 우선순위보다 우선한다.

<a id="c0-원점수-overlap-표본-확보가-먼저다"></a>

### 원점수 겹침 표본 확보. 원점수 overlap 표본 확보가 먼저다

1. 이미 허용·보존된 전체DF/전체21LA의 native score와 metadata만으로 common support를 조사한다. pilot으로 한정해6/3쌍밖에 없는 상태에서 새 GPU 실험을 먼저 확대하지 않는다. 전체캐시로 늘려도 충분하다고 가정하지 않는다.
2. 주 caliper는 기존과 같은 |s_B−s_S|≤0.02, 민감도는≤0.01과≤0.005다. source·codec(21LA transmission 포함)·길이bin 일치, 원길이 차이≤0.25초를 유지하고, 동일 화자가 가능한 엄격 층과 다른 화자를 허용한 층을 구분한다. 반응 결과를 보고 caliper를 넓히지 않는다.
3. 발화ID·분할·pair는 반응을 보기 전에 원점수와metadata로 고정한다. 정상은 ‘잘 맞힌 정상’만 골라서는 안 된다. 스푸프와 같은 낮은 native score의 어려운 정상도 포함돼야 한다. baseline score에 따른 선택이며 변형 반응에 따른 선택은 금지한다.
4. score 구간별 양 클래스 수·기여 화자·사용가능 pair·남은 baseline 차이를 보고한다. 서로 겹치지 않는 구간은 분석 대상에서 제외하고 대상 모집단의 범위를 명시한다. 전체표본의 조건부 효과를 외삽하지 않는다.
5. 사전 실행 가능성 기준은 한 도메인에서 완화 matching≥200쌍 및 양 클래스 각각≥20개 화자다. 이는 검정력 보장이 아닌 예산상 최소 기준이다. 기준 미달이면 효과를0으로 결론내리지 않고 ‘현재 자료로 주질문 판정 불가’로 둔다. 실제 표본·화자 상관·유의수준을 반영한MDE를 결과를 보기 전에 계산하고 임계효과0.05를 구별할 수 없는 경우에도 판정 불가로 둔다. 엄격matching의 적은 결과를 완화matching으로 숨기지 않는다.

<a id="c1-같은-점수에서-같은-변형에-대한-반응을-직접-비교한다"></a>

### 정상·위조의 변형 반응 비교. 같은 점수에서 같은 변형에 대한 반응을 직접 비교한다

각 고정pair에서 `d_B=s(T(x_B))−s(x_B)`, `d_S=s(T(x_S))−s(x_S)`를 구하고 주량을 `D=d_S−d_B`로 둔다. 이는 서로 다른 native score 집단의 전체평균 차이와 다르다. 클래스별s/duration 차이와 s_after도 함께 보고한다.

- 사전방향 가설: `E(D)>0`은 같은 출발점에서spoof가정상쪽으로더이동한다는 뜻이다. 실용 후보 기준은 동시구간 하한>0.05다. 그와 별도로 정상의 `E(abs(d_B))` 상한<0.02가 성립해야 ‘정상유지/spoof정상이동’이라고 부른다. D>0만으로 정상유지가 증명되지는 않는다.
- pair의 native score가 완전히 같지 않으므로 caliper 축소와 유연한native score 조건보정에서도 방향·크기가 유지되는지 본다. 작은 score차이에 대한 반응함수의 큰기울기가D를만들었을 가능성을 남겨두지 않는다. 공통support가없는곳에서 보정회귀로 값을 만들어내지 않는다.
- 평균차이가없어도 분산·비선형반응차이가있을수있다. 분포·강도별반응은 보조분석이며, 평균차이실패를 모든조건부정보의부재로해석하지않는다. ‘원래점수는같지만변형뒤점수가달라짐’과 ‘원래점수차이를반영한이동량’도구별한다.
- 고정후보는 R2-10 layer attention tau1, native4.0375초→1.5초 U, 같은1.5초 W→U 세 가지다. crop은긴원음부분집합에서따로분석한다. 마지막두비교를나란히둬내용감소와반복문맥을구분한다. tau0.5·2/3초는강도보조분석이며좋은강도를골라주결과를바꾸지않는다. 내부attention개입과음성변형을같은종류로부르지않는다.
- 후보3개×도메인2개에대한D주비교6개를한family로고정해Bonferroni동시95%구간을쓴다. 정상안정성6개도별도family로보고하며,두family를동시에통과했다고주장할때는전체12개에대한보정을추가한다. 충분한독립화자와원발화종속성정보가없으면확증판정을하지않는다.
- pair가화자를가로지르면pair를독립으로bootstrap하지않는다. 알려진원발화family를우선묶고,같은화자가들어간pair들을연결성분으로묶어군집재표집한다. 거대한성분으로독립단위가부족해지면단순발화bootstrap으로바꾸지말고판정불가를보고한다. 완화pair는관측되지않은화자차이가남은조건부연관이며위조의인과효과가아니다.

현재target을이미관찰했으므로위절차를앞으로고정해도과거탐색이사라지지않는다. 새미관측확인자료가없으면탐색적후속으로표시한다. 취소한DF4×3 CV를되살리거나target정답으로새readout을fit하는단계가아니다.

<a id="c2-주질문-다음에만-실용성을-평가한다"></a>

### 변형 반응 판독기의 전이 평가. 주질문 다음에만 실용성을 평가한다

기존4절의T/V학습→target전이는반응의실용성검증이다. 정상·위조의 변형 반응 비교에서정보가있어보이지만실용성이없을수있고,평균형태가실패해도다른반응특징이도움될수있다. 두결과를같은주장으로합치지않는다. **현재당장할일은원점수 겹침 표본 확보의전체캐시overlap점검이며,정상·위조의 변형 반응 비교표본이성립하기전에는전체GPU추론이나분류기학습부터시작하지않는다.**

첫 비교는 원하는 형태에 가까워 보이지만 원래 정상 점수 평균0.871198, spoof−0.950127로 출발점이 크게 다르다. 1.5초 무반복의 정상 최종 평균은0.995221로 천장 근처다. 정상의90백분위 절대 변화도0.353326이며 전부 유지된 것이 아니다.

같은 짧은 내용끼리 비교하면 ‘반복 제거가 spoof만 정상 쪽으로 보낸다’는 설명은 지지되지 않는다. 1.5초의 spoof−정상 이동량 차이는−0.058244이며 탐색95% 군집 구간은[−0.244870,+0.165812]다. 2초는−0.429243 [−0.620212,−0.204749]로 정상 이동이 더 크다. 이는 반복 제거의 모든 정보를 기각한 결과가 아니라, **주장한 선택적 이동의 방향을 지지하지 못한 결과**다.

1.5초 무반복 crop의 source별 정상/spoof 평균 변화는 ASVspoof +0.046158/+1.523840, VCC2018 +0.289347/+0.704227, VCC2020 +0.036565/+1.508121이다. VCC2018 정상에서 특히 유지가 성립하지 않는다. 원래 정상 전체471개에서 wrap 제거도 정상+0.501551/spoof+0.333542로 선택적 spoof 이동의 근거가 아니다.

### 2.3 이 질문의 직접 증거로 사용하지 않은 결과

- centroid 교체·길이 보정은 점수 함수를 바꾼 것이며 동일 음성의 입력 반응이 아니다. 길이별 centroid의 전체 DF 악화 결과를 변형의 성공/실패로 재해석하지 않는다.
- 최종 채널 keep/drop, gate·direction probe는 대체 readout이다. 반응 정보의 대조군으로는 쓸 수 있지만 음향 변형의 증거는 아니다.
- frontend 특징 복제와 layer 교체는 반복 민감도 경로를 좁힌 내부 개입이다. 실제 음성 변형·새 학습의 개선·일반화 증명은 아니다.
- 현재 최종 임베딩에 대칭 구면 회전만 주면 점수 차이가 `(1−cos epsilon)*s`가 되는 경우가 있다. 이것을 새 정보가 있는 확률 곡률로 주장하지 않는다.

- 엄격 규칙: source·speaker·codec,21LA transmission 일치; 길이 bin 일치; 원길이 차이≤0.25초; native score 차이≤0.02.

- lognorm을 추가 통제하지 않았다. 이번 질문은 우선 배포 scalar 이상의 정보 여부이며, norm까지 통제하면 표본은 더 줄 수 있다.

## 4. 후보의 구현과 변형 반응 판독기의 전이 평가 실용성 검증 세부 — 0절의 주실험 이후

### E1 — layer attention 반응에 추가 판별 정보가 있는가? 최우선

표본은 E1에서 T25,380(정상2,580/spoof22,800), V14,983(1,351/13,632), DF와21LA의 기존pilot 각20,000(2,000/18,000)을 전부 사용한다. 누락·오류 발화를 결과에 따라 제외하지 않는다. 재추출 전에 UID manifest·코드·checkpoint·feature·선택 규칙을 hash로 잠근다. 기존 target 캐시는 tau1 대응 검수용으로만 재사용할 수 있고 T/V의 response 출력은 현재 없다.

**질문:** 학습 도메인에서 배운 원본+개입 반응 결합기가 다른 공격·출처에서도 원점수만 사용하는 동급 결합기보다 나은가?

모델·centroid·frontend는 현재 checkpoint로 동결한다. 학습된 layer attention을 `a_l(x)`라 할 때, softmax 이후 실제 확률을

`a_l^(tau)(x)=(1−tau)*a_l(x)+tau/25`, `tau={0,0.5,1}`

로 치환한다. tau0은 native, tau1은 기존 R2-10과 같아야 한다. 나머지 연산과 RNG는 동일하다. tau0.5는 강도 의존성 검사다. 최종 temporal attention은 유지한다. tau1에서 R2-11을 더하는 것은 주결과 후의 보조 개입으로만 둔다.

대조는 다음과 같이 고정한다.

1. Native 원래 cosine.
2. P_scalar: native score의 cubic spline + lognorm + logduration + padding_fraction을 사용하는 class-balanced ridge logistic. source·codec·dataset ID를 예측 feature로 넣지 않는다.
3. P_response: P_scalar와 같은 항에 `d_0.5`, `d_1` 두 개만 추가.
4. P_mean: P_scalar에 세 view의 평균 점수 하나만 추가. `d_0.5,d_1`의 일반적인 양방향 조합과 같지는 않지만, ‘평균하기만 해도 되는가’를 평가한다. 원본과 변형 하나의 평균은 그 변형 delta와 원본으로 정확히 복원 가능하므로 독립된 기전 증거로 세지 않는다.
5. P_noise: P_scalar에 UID로 생성한 정규잡음2개를 추가. 같은 차원의 정규화·분류기 대조.

부모 EBM은 T에서 이미 학습됐으므로 T 성능은 독립 결과가 아니다. 모든 response 출력을 T/V에서 새로 계산하고, 두 결합기의 scaler/spline knot는 T만으로 fit한다. spline은 degree3/quantile5 knots, 중복 knot는 deterministic unique 처리한다. ridge C={0.01,0.1,1,10}, 각 모델은 V balanced log-loss로 선택하며 동점은 작은 EBM-FullContext 우선이다. V가 너무 쉬워 분별하지 못하면 선택력 부족으로 보고하며 target에서 tau/EBM-FullContext/feature를 재선택하지 않는다. seed는 fit 구현에 필요한 경우101/102/103 고정이며 결과를 보고 좋은 seed를 고르지 않는다.

주 지표는 고정 target에서 `LL(P_scalar)−LL(P_response)`다. 주 도메인은 DF,21LA 두 개다. 보조는 EER/AUROC와 V에서 bona FRR≤1%로 정한 각 모델별 threshold의 FAR/FRR다. 원점수의 단조 보정만으로 EER는 바뀌지 않지만 scalar 결합기는 norm·길이도 쓰므로 native와 따로 비교한다. 반응은 이 모든 공통 항을 넘어 이득이 있어야 한다.

**E1의 합격 범위:** 두 도메인의 LL 개선에 대해 동시95%를 위한 개별97.5% paired source×speaker 군집 구간의 하한>0. EER와 운용 오류는 모두 보고한다. 이 조건은 확률 예측 개선의 기준이며 EER 개선을 자동 뜻하지 않는다. EER 개선 주장은 별도 구간과 다중비교 family를 사전에 고정해야 한다. 이미 본 target의 사후 설계이므로 성공해도 탐색적 benchmark 전이 결과다. 미관측 외부 데이터가 확보되면 동일한 고정 모델로 한 번 확인해야 새 독립 일반화 근거가 된다.

**형태 가설은 별도 판정:** 정상 안정성은 각 출처의 평균 절대 delta에 대한 단측 상한이0.02 미만인지 본다. spoof는 평균 delta 단측 하한>0.05인지 본다. δ0.02/0.05는 보편 법칙이 아닌 이번 설계의 사전 실용 기준이며 민감도 δ0.01/0.05는 보조다. 출처별 양 클래스 각각 기여 화자10개 미만이면 강한 판정은 하지 않는다. 테스트할 출처×클래스 cell을 추출 전에 metadata로 고정하고 총K개 cell에 Bonferroni `alpha=.05/K`를 사용한다. bootstrap 꼬리 해상도가 부족하면 draw를 충분히 늘리거나 판정 불가로 둔다. 평균 안정성과 별도로 p90/p95 절대 delta·큰 이동 표본 비율을 반드시 보고한다. 현재 R2-10 DF 결과는 이 엄격한 형태를 지지하지 않는다.

원점수 overlap에서는 위 고정 matching을 추가로 계산하되 충분하지 않으면 판정 불가로 남긴다. 어려운 정상/스푸프를 target의 delta로 골라 새 검증셋으로 만들지 않는다. class를 조건화한 통계는 예측적 연관이며 class의 인과효과가 아니다.

**비용/우선순위 이유:** layer attention은 XLS-R 이후 연산이라 같은 frozen hidden states를 RAM에서 재사용할 수 있다. 3번의 파형 backbone 추론 없이 backend 개입들을 계산할 수 있다. 서버 파일에 hidden states를 저장하지 않는다. 실제 메모리·시간은 소규모 QC로 측정해야 한다.

### E2 — 무반복 short crop의 반응은 내용 손실인가, 반복 문맥인가? 두 번째

현재 metadata의 원길이≥4.0375초인 고정 전체 부분집합은 T6,771(정상576/spoof6,195), V4,422(402/4,020), DF_pilot4,548(570/3,978),21LA_pilot2,783(442/2,341)이다. 샘플 수 기준≥64,600과 duration 필드의 대응을 실행 전 원본 manifest에서 재검증하고, 차이가 있으면 label/score를 보지 않고 표본 정의를 정정·기록한다. 1.5·2·3초×head/tail×U/W의12개 view는 같은 발화의 반복 측정이지12배의 독립 표본이 아니다.

초기 기전 대상은 원음≥64,600 sample인 발화다. 기본 입력을 모든 조건에서 동일한 첫64,600 sample로 고정한다. 그 안의 head/tail1.5·2·3초를 모두 사용하고 위치별 유리한 결과를 고르지 않는다.

각 동일 segment에 두 branch를 만든다.

- U: segment를 실제 길이로 입력.
- W: 같은 segment를64,600 sample까지 기존 wrap 방식으로 반복.

native4.0375초와 U의 차이는 내용 감소+문맥 길이를 함께 바꾼다. U−W는 음성 내용의 집합을 맞추지만 반복·전체 문맥 길이를 함께 바꾸므로 순수 주기성 효과라고 부르지 않는다. U의 XLS-R hidden states를 시간축에서 W와 같은201frame으로 복제한 backend 대조는 기전 확인용으로 별도 둔다. 실제 파형 변형으로 해석하지 않는다.

변형별 임베딩을 평균하지 않고, 먼저 segment별 scalar 점수를 얻고 head/tail 점수를 발화별 평균한다. 길이3개별 `d_U_vs_native`, `d_W_vs_native`, `d_U_minus_W`를 기록한다. 이들은 대수적으로 종속이므로 모두 독립 feature로 넣지 않는다. 후속 readout은 길이별 U−native와 W−native6개만 사용하고 E1과 같은 scalar/noise 대조를 쓴다. 입력 유효길이는 각각 고정하고 나머지 batch padding은 올바른 frontend/pooling mask로 제외한다.

T/V의 긴 발화에서 fit/선택하고 target의 같은 길이 조건으로 전이 평가한다. 4.0375초 미만 발화에 대한 결론으로 확대하지 않는다. 전체 발화에 적용하려면 짧은 길이에서 같은 측정이 가능하도록 별도 후속 프로토콜이 필요하다. 긴 target 표본 수와 source×class×speaker 분포를 먼저 잠그고, 긴 정상만 또는 긴 spoof만 유리하게 선택하지 않는다. E1을 보지 않고 E2의 후보·길이·위치 규칙을 유지한다.

처음에는 두 조건의 차이를 읽는 실험만 하며 새 EBM 재학습·centroid 갱신·일관성 loss 추가는 하지 않는다. 반응의 정보와 transfer가 확인된 뒤에 학습 목적함수 변경을 별도로 검토한다.

## 5. 공통 QC·실패 판정·운영

1. 출처×클래스×원길이×codec, speaker/family ID와 표본 수를 metadata만으로 고정한다. 이번 보고서에서 본471개와pilot은 관찰 이력이 있으므로 새 확인 표본이라고 부르지 않는다.
2. tau0 원점수·h/z는 기준 캐시 오차≤1e−5, tau1은 기존 R2-10 공통 QC로 확인한다. pooling noise와 crop RNG는 발화별 고정하며 같은 조건 재실행과 양GPU에서 차이를 측정한다. 무작위 내부 noise를 반응으로 잘못 읽지 않는다.
3. 원음·원본 코드·checkpoint를 로컬로 전송하지 않는다. 기존 컨테이너와 `CUDA_VISIBLE_DEVICES=0,1`만 사용한다. 시작 전에 실제 프로세스·screen 창·컨테이너·GPU 상태를 확인한다. 실행 중 실험을 중단·재시작하지 않는다.
4. 별도 sidecar·새 고유 결과 경로를 사용하고 존재하면 실패한다. 원래 로거의 동명 결과 삭제 경로를 사용하지 않는다. backbone states는 메모리에서만 재사용하며, 허용된 최종h/z·점수·metadata만 기존 규칙대로 보관한다.
5. 한 변형의 클래스 평균 격차만으로 성공이라고 하지 않는다. 정상 안정성, 같은 native score의 overlap, 강한 scalar 대조, 다른 공격/출처의 전이 성능을 구분해 보고한다.
6. 형태 기준 실패+readout 이득 없음이면 해당 후보는 중단한다. 형태 실패지만 readout 이득이 있으면 ‘선택적 정상 이동’ 대신 ‘차등 반응을 이용한 예측 개선’이라고 보고한다. native와 반응 결합의 이득이 단순 평균/metadata 대조로 설명되면 곡률 기전을 주장하지 않는다.
7. 이번 E1은 내부 attention 경로, E2는 큰 입력 crop 반응이다. 둘 다 성공만으로 DetectGPT의 생성 확률 곡률을 검증한 것이 아니다. 국소 곡률은 별도 대칭 소변형과 step-size 수렴,1차 반응 대조를 갖춘 후속 질문이다.
