# 4.0375초 상한 비반복 학습 실험 목적과 완료 후 검증 범위

사용자는30분마다점검하고종료후우리실험목적에따라자율분석하도록요청했다. 현재최종paired평가는그대로진행하며학습·모델·기존평가를수정하거나중복실행하지않는다. 동일예약ID `ebm-b-6`은현재30분간격·ACTIVE다.

검증할질문은반복연장이짧은정상의centroid거리와잔여방향/오류에영향을주는지, 4.0375초 상한 비반복 학습의반복없는0패딩+mask학습이이문제를완화하는지, 이때spoof수락이늘어나는지다. 성능향상을전제로결론을내리지않는다.

먼저현재고정50epoch모델의전체평가를검산한다. 동일UID/동일4.0375초 상한 비반복 학습입력에서배치 240 고정 길이 반복 입력 학습과4.0375초 상한 비반복 학습의EER·dev기준운영오류·길이별표본수와paired불확실성을비교한다. 과거반복평가와현재평가를구분하고target에서threshold/epoch를선택하지않는다.

기하와반복민감도를검증하는추가추론은두고정모델×두입력정책(반복/비반복)의2×2로구성한다. 원음의동일한앞최대64600sample을기준으로짧은입력의반복여부만정책적으로바꾸며, 긴입력은no-op대조로둔다. 변환이길이·문맥도함께바꾸므로‘순수주기성만’의효과로단정하지않는다. 공식benchmark의noise1e-5와진단의noise통제설정을명확히구분한다.

추가추론표본은사전길이4구간×class2×target3의각층에서최대32개,총최대768개다. UID hash와speaker round-robin만으로선택하고score/오류/embedding으로사례를고르지않는다. 선택목록과실행프로토콜을추론전에잠그고수정하지않는다. 예를들어고정선택문자열 `EBM-B-mechanism-20261107-v1`와UID의SHA256으로정렬하고speaker내순번을먼저균형화해각층상위32개를쓴다. 빈층과소표본을명시하고이균형표본을전체모집단비율로읽지않는다.

분석용160차원embedding과각모델의learnedcentroid에서cosine각도·정상/spoof분리·잔여방향분포/집중도를확인한다. Learnedcentroid는정상산술평균이아니며,다른모델의latent축은정렬없이동일한물리축으로해석하지않는다. PCA시표본범위와설명분산을밝히고축에음향적의미를부여하지않는다. 원음과SSLhiddenstates는저장/반출하지않는다. 제한된추론은full평가종료와GPU유휴를확인한후기존컨테이너·CUDA_VISIBLE_DEVICES=0,1로수행한다.

최종보고는가설별지지·반박·미확정과근거를제시한다. 배치 240 고정 길이 반복 입력 학습과4.0375초 상한 비반복 학습은sampler·codec실행상태·학습구현에차이가있어이비교만으로학습반복제거의단독인과효과를증명할수없다. 입력개입으로식별가능한효과와추가matched-A학습이필요한효과를구분한다. 새동일 구현의 반복 입력·비반복 입력 대조재학습은자동추가하지않고필요한통제를구체적으로보고한다. 최종검산·보고·그림까지완료한뒤에만예약을삭제한다.
