# EBM 최종 임베딩의 좌표 부분집합을 이용한 코사인 점수 진단

> **해석 갱신: 2026-11-05 17:47 KST.** 기존 좌표 부분집합의 DF 결과와 새 학습 gate/metric 전이 결과를 분리해 판정한다. 최신 통합 판정은 [방향·채널 전체 분석](../ebm_frozen_all_results_20261105.md)에 있다. 기존 실험의 수치와 그림은 해당 실행의 결과로 보존한다.

작성일: 2026년 11월 5일. 기존 EBM의 학습된 파라미터를 고정한 상태에서 수행한 탐색적 분석이다. 본 문서의 ‘채널’은 최종 160차원 임베딩의 좌표를 의미한다.

## 1. 가설

다음 두 질문을 확인하고자 했다.

1. 학습 데이터에서 정상·스푸프 분리도가 높은 좌표를 제거하면, 같은 수의 무작위 좌표를 제거한 경우보다 기존 코사인 점수의 성능이 크게 저하되는가?
2. 최종 임베딩의 일부 좌표만 사용해도 전체 160개를 사용하는 경우와 비슷한 판별 성능을 얻을 수 있는가?

첫 질문은 채널별 클래스 분리도와 기존 점수의 의존성이 연결되는지를, 둘째는 현재 점수에 대한 신호의 중복 가능성을 조사한다. 일부 좌표만으로 EER가 유지되더라도 다른 좌표의 정보가 모두 불필요하다는 결론은 별도로 검증해야 한다.

## 2. 실험

EBM의 전체 추론 과정을 거쳐 최종 LayerNorm 이후, OC 점수 계산의 L2 정규화 이전에 얻은 160차원 벡터를 z, 학습된 centroid를 c라고 정의했다. 전체 좌표를 사용하는 기준 점수는 다음과 같다.

\[
s_{\mathrm{all}}=\frac{z^\top c}{\|z\|_2\|c\|_2}.
\]

좌표 집합 K만 남기는 경우, 임베딩과 centroid에서 동일한 좌표를 선택하고 두 벡터를 각각 다시 정규화했다.

\[
s_K=\frac{z_K^\top c_K}{\|z_K\|_2\|c_K\|_2}.
\]

좌표 수는 160개에서 1개까지 단계적으로 줄였다. 학습 데이터의 클래스 분리도에 따라 상위 좌표 유지, 하위 좌표 유지, 무작위 좌표 유지의 세 조건을 비교했다.

모델·centroid의 재학습, 새로운 판별기의 학습, 별도 채널 가중치 학습은 하지 않았다. 동일하게 저장된 임베딩으로 코사인 점수만 다시 계산했다. 벡터 크기를 별도의 판별 입력으로 사용하지 않았다.

**원래 160차원 벡터를 생성하는 신경망과 LayerNorm 계산은 모두 유지했다.** 따라서 이 실험은 처음부터 1·2차원만 출력하도록 학습한 모델이나 추론 연산량 감소를 평가한 것이 아니다.

## 3. 수행 방식

### 3.1 모델과 데이터

기존 EBM 구현으로 별도 학습한 한 개의 checkpoint를 사용했다. 학습 조건은 50 epochs, batch size 160, learning rate 1e-5, seed 1이며, XLS-R frontend는 이 학습 구간에서 고정했다. 모든 좌표 비교에서 같은 모델·centroid·입력 구간·추출 설정을 사용했다. 본 수치를 논문 보고 성능의 재현 결과로 제시하는 것은 아니다.

frontend는 facebook/wav2vec2-xls-r-300m이다. OC scale은 20, 정상/스푸프 margin은 각각 0.9/0.2, BPL scale은 30이었다. 학습 배치의 정상:스푸프 비율은 1:9이며 OC 클래스 가중치는 정상 5, 스푸프 5/9였다.

| 데이터 | 표본 수 | 정상 / 스푸프 | 사용 목적 |
| --- | ---: | ---: | --- |
| ASVspoof 2019 LA train | 25,380 | 2,580 / 22,800 | 좌표별 클래스 분리도 산출 |
| ASVspoof 2019 LA development의 화자 분리 부분집합 | 14,983 | 1,351 / 13,632 | 참고 성능 및 기존 운용 문턱값 설정 |
| ASVspoof 2021 DF eval의 고정 부분집합 | 20,000 | 2,000 / 18,000 | 주 진단 |

development 부분집합은 공식 development의 화자를 seed 11로 무작위 순열한 뒤 그중 10명의 발화를 선택한 것이다. 나머지 화자의 발화는 이 분석에 사용하지 않았다.

2021 DF는 공식 eval 533,928개 중 클래스별로 발화 ID의 SHA256 해시 순서를 이용해 점수와 무관하게 고정 추출했다. 재현용 정렬 키는 문자열 ‘DF-pilot-20261105|’와 발화 ID를 이어 붙인 SHA256이다. 정상 2,000개와 스푸프 18,000개를 각각 선택했다. 표본에는 110개 공격과 9개 코덱 조건이 포함됐다.

이 표본의 클래스 비율은 전체 평가셋과 다르다. EER는 각 클래스 내부의 오류율로 계산했으며, 본 문서의 2021 DF 수치는 **전체 평가셋 성능이 아닌 20,000개 고정 표본의 결과**다.

임베딩 추출은 평가 모드, 발화당 1개 구간, 16 kHz의 64,600 samples 설정을 사용했다. 긴 입력은 앞 구간을, 짧은 입력은 기존 평가 로더의 wrap padding을 사용했다. pooling의 확률적 연산을 위해 발화별 난수 seed를 고정했고 모든 좌표 조건에서 동일한 추출 결과를 사용했다.

모델 식별용 checkpoint SHA256은 다음과 같다.

104873703a57cad98b686d770e0860e031a2cf9abef79b72668780c1660e0b24

### 3.2 좌표 순위: 학습된 가중치와 구별

순위는 attention 가중치, centroid 원소의 크기, gradient 중요도로 정하지 않았다. ASVspoof 2019 LA train에서 각 좌표의 정상·스푸프 분리도를 Fisher score로 계산했다.

정상 클래스의 좌표 j 평균·분산을 μ_B,j, σ²_B,j, 공격 종류 a의 스푸프 평균·분산을 μ_a,j, σ²_a,j라고 하면,

\[
J_{a,j}=
\frac{(\mu_{4.0375초 상한 비반복 학습,j}-\mu_{a,j})^2}
{\sigma_{4.0375초 상한 비반복 학습,j}^{2}+\sigma_{a,j}^{2}+10^{-8}},
\qquad
J_j=\frac{1}{6}\sum_{a\in\{\mathrm{A01},\ldots,\mathrm{A06}\}}J_{a,j}.
\]

분산은 표본분산으로 계산했다. 여섯 공격을 같은 가중치로 평균해 특정 공격의 표본 수가 순위를 지배하지 않도록 했다. 점수가 높을수록 해당 학습 데이터에서 클래스 평균 차이가 분산에 비해 크다는 뜻이다. 이를 실제 모델의 인과적 중요도나 다른 평가셋의 유용성과 동일시하지 않았다.

| 조건 | 남기는 좌표 |
| --- | --- |
| Fisher 상위 유지 | J_j가 가장 높은 k개 |
| Fisher 하위 유지 | J_j가 가장 낮은 k개 |
| 무작위 유지 | 고정된 무작위 순열에서 선택한 k개 |

무작위 조건은 seed 200–219의 NumPy default_rng로 생성한 160좌표 순열에서 뒤 k개를 선택했다. 같은 seed에서 작은 집합은 큰 집합에 포함된다. 20개 결과를 모두 보고하고 중앙값과 범위를 제시했다.

초기 실험은 Fisher 상위 8·16·40·80개 제거였으며, 각각 Fisher 하위 152·144·120·80개 유지에 해당한다. 이후 유지 수를 80개부터 1개까지 확장했다. 각 단계의 순위·마스크는 새 평가 전에 고정했지만, **유지 수의 확장은 이전 결과를 관찰한 뒤 순차적으로 이루어진 탐색**이다. 평가셋에서 순위를 새로 계산하거나 가장 좋은 무작위 집합만 선택하지 않았다.

### 3.3 평가와 불확실성

정상을 양성으로 두고 높은 점수가 정상에 대응하도록 EER와 AUROC를 계산했다. EER는 동점 점수들을 하나의 집단으로 처리한 ROC의 선형 보간값이다. AUROC는 전체 문턱값 범위의 순위 성능을 확인하기 위해 함께 보고했다.

부분집합과 전체 좌표의 EER 차이는 ‘부분집합 EER − 전체 EER’의 percentage point(pp) 단위다. 양수면 악화다. 출처 corpus와 화자 ID를 함께 식별한 93개 그룹을 동일하게 재표집하는 paired bootstrap 2,000회(seed 7301)로 개별 95% 구간을 계산했다.

원발화·합성·재인코딩 파생본을 연결한 완전한 family 정보는 확보하지 못했다. 따라서 화자 그룹 외 의존성이 남을 수 있다. 구간은 고정된 모델과 점수에 조건부이며 학습 seed의 변동을 포함하지 않는다. 여러 유지 수와 반복 탐색 전체에 대한 동시 신뢰구간이나 사전 지정 비열등성 검정도 아니다. 무작위 부분집합의 최소·최대 범위는 마스크 선택의 변동으로, 표본 신뢰구간과 구별했다.

### 3.4 1차원 코사인과 수치 검증

1개 좌표만 남기고 선택 값이 0이 아니면,

\[
s_{\{j\}}=\frac{z_jc_j}{|z_j||c_j|}
=\operatorname{sign}(z_j)\operatorname{sign}(c_j)
\]

이므로 점수는 정확히 +1 또는 −1이다. 동점을 임의로 나누지 않았고, 클래스별 부호 개수로 계산한 EER와 전체 ROC 계산을 대조했다. 1차원의 보간 EER는 실제 한 문턱값에서 두 오류율이 정확히 같아진다는 뜻은 아니다. 이번 선택 값에는 0이 없었다.

임베딩·점수·label의 행 정렬과 파일 해시를 검증했다. 선택 좌표를 직접 자르는 방식과 제외 좌표를 0으로 만드는 방식의 점수를 대조했고, 2차원 점수는 atan2로 구한 각도 차이의 코사인으로도 확인했다. 앞선 2개 좌표의 23개 조건(기준 점수 포함)은 재계산 시 오차 0으로 재현됐다. 전체 ROC, 동점의 직접 개수 계산, 순위 기반 AUROC의 독립 재계산도 일치했다.

두 곡선은 교차한다. 두 오류율이 비슷해지는 구간에서는 하위 2개가 유리하지만 정상 오거부를 더 낮게 제한하는 구간에서는 전체 160개가 유리했다.

별도로, 2019 LA development 부분집합에서 정상 오거부율 약 1%를 목표로 정한 기존 문턱값 0.9883067190214367을 고정 적용한 DF 결과도 계산했다. development에서 실제 정상 오거부율은 0.9623%였다.

| 점수에 사용한 좌표 | DF 정상 오거부율 (%) | DF 스푸프 통과율 (%) |
| --- | ---: | ---: |
| 전체 160개 | 39.00 | 0.0111 |
| Fisher 하위 2개 | 11.45 | 0.8167 |
| Fisher 하위 1개 | 4.45 | 2.0556 |

이 표는 같은 수치의 문턱값을 유지했을 때의 점수 분포 변화를 보여준다. 부분집합마다 development에서 문턱값을 다시 보정한 비교는 아니므로, 정상 오거부 감소만을 운용 개선으로 해석하지 않는다.

### 4.3 선택된 두 좌표와 한 좌표의 확인

하위 2개는 원래 160차원에서 113번과 95번 좌표였다. 번호는 0부터 센 index다. 두 좌표에 대응하는 centroid 값은 약 (0.080407, 0.080406)이었다.

| 실제 클래스 | z[113] 평균 | z[95] 평균 |
| --- | ---: | ---: |
| 정상 | 1.041166 | 1.084666 |
| 스푸프 | −0.525601 | −0.694368 |

전체 DF 표본에서 두 좌표의 상관은 0.973238이었다. 이 수치에는 클래스 평균 차이의 영향도 포함되며, 표현 전체의 내재 차원이 1 또는 2라는 뜻은 아니다.

95번 한 좌표에서는 정상 2,000개 중 1,911개(95.55%)가 양수, 스푸프 18,000개 중 17,630개(97.9444%)가 음수였다. 선택된 최종 요약값에 이미 판별 신호가 담겨 있다는 점을 직접 확인했다. 전체 신경망이 복잡한 입력 정보를 처리한 뒤 생성한 좌표이므로, 소수 좌표로 일부 판별력이 유지되는 현상 자체가 계산상 불가능한 것은 아니다.

## 5. 해석

### 5.1 확인된 관찰

현재 checkpoint의 최종160좌표 중 특정 부분집합만 사용해도 이 DF pilot에서 낮거나 비슷한 EER의 점 추정치를 얻었다. 하위2개 EER2.9222%는 native3.35%보다 낮았지만,차이 CI는0을 포함했다. 부분집합에 따라 성능이 달랐고 T의 높은 단변량 Fisher 순위가 DF의 좋은 cosine 부분집합을 보장하지 않았다.

같은 표본에서 하위2개의 AUROC는0.987659로 전체0.995943보다 낮았다. V EER도0.1907%로 native0%보다 높았다. 전체160개와 두 좌표의 ROC는 교차하며,정상거부율1% 이하에서는 전체 표현이 유리했다. 따라서 현재 EER 지점의 관찰을 전체 성능 동등성 또는 비열등성 입증으로 바꾸지 않는다.

### 5.2 새 gate/metric 실험과의 관계

후속 P1은 T에서 static/dynamic gate와 같은 크기 MLP를 학습하고 V에서 선택했다. dynamic의 DF 평균 EER는3.342593%,native 대비 개선0.007407pp의99% CI는[−0.054719,+0.065027]이다. 21LA pilot은0.80%로 같았다. static과 P2 metric은 epoch0 identity가 선택됐다.

즉,일부 좌표만 읽어도 낮은 EER가 나온다는 관찰이 **입력별로 학습한 gate가 전이 EER를 개선한다는 주장으로 이어지지 않았다.** P1은 c를 고정한 bounded 변환이고 기존 F1은 z/c에 같은 binary mask를 준 점수다. 서로 다른 점수 정의와 학습 범위를 혼동하지 않는다.

### 5.3 아직 확대할 수 없는 결론

- 전체 encoder·160차원 LayerNorm을 계산한 뒤 점수에 쓰는 좌표만 줄였다. 처음부터2차원인 모델·추론 연산량 절감·표현의 본질적 차원을 검증하지 않았다.
- 113·95는 T-Fisher 하위 좌표다. 나머지158개가 모두 잡음이거나 어떤 부분집합에도 불필요하다고 볼 수 없다.
- 1차원 cosine은 연속 각도 대신 부호±1만 남는다. 그 EER는 보간 ROC 값이며 실제 특정 문턱값의 정상거부·spoof통과와 구분한다.
- 같은 숫자의 native V threshold를 모든 부분집합에 적용한 오류 변화와,각 점수별 V threshold를 새로 고정한 운용 비교를 구분한다.
- 10→2→1개 확장은 이미 관찰한 DF 표본에서 이어진 탐색이다. 개별 CI가 이전 탐색 전체를 보정하지 않는다.

### 5.4 신규 panel의 상태

명세의 원래169조건,직교회전3개의25% 대조,각 mask의 V threshold,10,000회 speaker/mask 공동 재표집을 수행 중이다. 전체 완료·검수 전에는 좌표계에 무관한 채널 집중이나21LA 재현을 확정하지 않는다. DF/21LA는67화자그룹을 공유하고 source-family도 미해결이다. 최신 완료 여부와 수치는 [전체 분석](../ebm_frozen_all_results_20261105.md)을 따른다.
