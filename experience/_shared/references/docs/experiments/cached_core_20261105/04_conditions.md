# ④ 음성 특징의 방향은 정상·위조 여부와 출처·압축 방식·길이에 어떻게 관련되는가

> **해석 갱신: 2026-11-05 17:47 KST.** 기존 K=4 NMI와 새 DF/21LA 전체 잔여방향의 class별 분산 통계를 함께 해석한다. 최신 통합 판정은 [방향·채널 전체 분석](../ebm_frozen_all_results_20261105.md)에 있다. 기존 실험의 수치와 그림은 해당 실행의 결과로 보존한다.

2026년 11월 5일 수행한 분석이다. 음성 위조 탐지 모델 EBM이 이미 추출해 저장한 특징을 사용했다. 여기서 **정상 음성**은 실제 음성, **스푸프 음성**은 합성·변조 등으로 위조한 음성을 뜻한다. [네 실험 목록](README.md).

## 1. 가설

**특징 벡터에서 기존 탐지 점수로 요약되지 않는 방향에는 정상·스푸프 여부와 데이터 수집·처리 조건이 함께 반영될 수 있다.**

모델은 음성 한 개를 160개의 숫자로 이루어진 특징 벡터로 표현한다. 기존 탐지 점수는 이 벡터가 학습된 기준 벡터와 얼마나 비슷한 방향을 향하는지 나타내는 코사인 유사도다. 이번에는 두 벡터의 길이를 각각 1로 맞추고, 음성 벡터에서 기준 벡터를 향하는 성분을 뺀 뒤 남는 성분의 길이를 다시 1로 맞췄다. 이를 ‘잔여 방향’이라고 부른다. 같은 코사인 점수의 음성도 서로 다른 잔여 방향을 가질 수 있다.

잔여 방향이 비슷한 음성끼리 묶은 집단을 ‘군집’이라고 한다. 이 군집이 정상·스푸프를 구분하는지, 음성의 출처나 길이 같은 조건을 구분하는지 확인했다. 정상끼리만 비교하거나 스푸프끼리만 비교해도 조건과의 관계가 남는지 함께 조사했다.

방향이 정상·스푸프와 관련된다는 사실만으로 음성 위조의 특징만을 담고 있다고 볼 수는 없다. 데이터 조건과 관련된다는 사실만으로 불필요한 정보라고 판단할 수도 없다. 두 관계가 함께 존재하는지 확인하는 것이 이번 실험의 질문이다.

## 2. 실험

ASVspoof 2019 LA 학습 데이터에서 잔여 방향이 비슷한 음성들을 네 군집으로 나눴다. 군집 중심을 정한 뒤에는 이를 바꾸지 않고, 같은 대회의 개발 데이터 일부와 ASVspoof 2021 DF(DeepFake) 평가 데이터의 고정 표본에 적용했다.

DF 표본에서 군집 배정과 다음 항목의 관계를 비교했다.

- 정상·스푸프 여부
- 출처: 음성이 속한 원래 음성 자료 모음
- 코덱: 음성을 압축·복원하는 방식
- 발화 길이 구간
- 패딩 비율 구간: 모델의 고정 입력 길이를 맞추기 위해 원래 음성 외에 채워 넣은 부분의 비율

전체 표본뿐 아니라 정상 음성만, 스푸프 음성만 모은 경우에도 조건과의 관계를 계산했다. 이를 통해 출처별 정상·스푸프 비율 차이만으로 군집과 출처의 관계가 나타난 것인지 일부 구별하고자 했다. 군집별 정상 비율, 길이 중앙값, 패딩 비율 중앙값도 기록했다.

## 3. 수행 방식

### 사용한 데이터

이미 저장한 특징 벡터, EBM의 학습된 기준 벡터(centroid), 음성별 출처·길이 등의 정보를 재사용했다.

| 데이터 | 표본 수 | 이번 실험에서의 역할 |
| --- | ---: | --- |
| ASVspoof 2019 LA 공식 학습 데이터 | 25,380개 | 일부 표본으로 군집 중심을 학습하고, 길이·패딩 구간의 경계를 정함 |
| ASVspoof 2019 LA 공식 개발 데이터 중 화자별로 나눠 둔 선택 부분 | 14,983개 | 고정된 군집 중심을 적용함 |
| ASVspoof 2021 DF 평가 데이터의 고정 표본 | 20,000개 | 군집과 정상·스푸프 여부 및 데이터 조건의 관계를 분석함 |

DF 표본은 정상 2,000개와 스푸프 18,000개다. 전체 DF 평가 데이터를 사용한 것은 아니다. 새 음성 특징을 추출하거나 EBM을 다시 학습하지 않았다.

### 군집 중심을 정하고 다른 데이터에 적용하는 방법

음성 특징 벡터를 z, EBM이 학습한 기준 벡터를 c라고 표기한다. c는 이번 분석 표본에서 새로 구한 평균이 아니다. 두 벡터의 길이를 1로 맞춘 값을 ẑ, ĉ라고 할 때 다음과 같이 잔여 방향 u를 구했다.

    s = ẑ · ĉ          기존 코사인 탐지 점수
    r = ẑ - s ĉ        기준 벡터에 수직으로 남는 성분
    u = r / ||r||       남는 성분의 길이를 1로 맞춘 잔여 방향

군집 중심을 정할 때는 2019 LA 학습 데이터에서 정상 2,500개와 스푸프 2,500개를 무작위로 뽑았다. 같은 표본을 다시 뽑을 수 있도록 난수 시드 17을 사용했다. 정상·스푸프 정답은 표본 수를 맞추는 데만 썼으며, 군집을 만드는 계산에는 넣지 않았다.

방법은 방향 간 코사인 유사도를 사용하는 구면 k-means(spherical k-means)다. 군집 수는 4개로 고정했다. 초기 중심에 따른 차이를 줄이기 위해 난수 시드 501~505로 다섯 번 계산하고, 학습 표본과 각 표본에 배정된 중심 사이의 코사인 유사도 합이 가장 큰 결과를 선택했다. 개발 데이터나 DF의 성능을 보고 군집 수 또는 초기값을 고르지 않았다.

DF 음성은 자신의 잔여 방향과 코사인 유사도가 가장 큰 중심의 군집에 배정했다. 이때 중심을 DF에 맞춰 다시 학습하지 않았다.

길이 구간의 경계는 2019 LA 학습 데이터의 길이를 정렬했을 때 아래에서 20·40·60·80%에 해당하는 값으로 정했다. 패딩은 없는 경우를 별도로 구분하고, 패딩이 있는 학습 음성의 패딩 비율에서 25·50·75%에 해당하는 값을 경계로 사용했다. DF에서 경계를 바꾸지 않았다. DF 표본에는 출처 3개 범주와 코덱 9개 범주가 있었다.

### 군집과 정답·조건의 연관을 측정하는 방법

정규화 상호정보량(NMI, normalized mutual information)을 주 지표로 사용했다. 군집 번호와 정상·스푸프 여부 또는 데이터 조건이 얼마나 연관되는지 요약하는 값이다. 0에 가까우면 이 표본과 군집에서 연관이 작고, 값이 커질수록 연관이 크다. 이 수치는 원인 관계나 탐지 정확도를 나타내지는 않는다. 두 범주 배정의 일치를 우연 수준에 맞춰 보정하는 조정 랜드 지수(adjusted Rand index)도 별도로 계산했다.

출처·코덱·길이·패딩은 전체 표본, 정상만, 스푸프만의 세 범위에서 연관을 계산했다. 이 분석은 관찰한 표본의 관계를 요약하는 기술 통계이며, 조건부 가설검정의 p값이나 군집 연관의 부트스트랩 신뢰구간은 계산하지 않았다.

## 4. 결과

### DF 표본의 군집과 정상·스푸프 여부 및 데이터 조건의 연관

각 칸은 NMI다. ‘정상만’과 ‘스푸프만’ 열은 해당 종류의 음성만 모아 다시 계산한 값이다.

| --- | ---: | ---: | ---: |
| 정상·스푸프 여부 | 0.264455 | — | — |
| 출처 | 0.118216 | 0.343788 | 0.102867 |
| 코덱 | 0.004659 | 0.023151 | 0.002396 |
| 길이 구간 | 0.078156 | 0.072378 | 0.083180 |
| 패딩 비율 구간 | 0.080117 | 0.076551 | 0.084641 |

군집은 정상·스푸프 여부와 연관됐으며 출처·길이·패딩 비율과도 연관됐다. 특히 정상 음성끼리만 보아도 출처와 군집의 NMI는 0.343788이었다. 출처별 정상·스푸프 비율 차이만으로 설명되지 않는 관계가 관찰된 것이다. 코덱과의 연관은 이번 네 군집에서는 비교적 작았다.

군집 번호에는 크기나 우열의 의미가 없다. 군집 1은 정상 음성 비율이 높았고, 군집 3은 더 짧고 패딩 비율이 큰 음성들로 구성됐다. 이런 구성 차이만으로 군집을 만든 음향적 원인을 확정할 수는 없다.

### 데이터 조건을 함께 입력해도 방향이 도움이 되는가

[실험 ①](01_direction.md)에서는 DF 안에서 학습용 화자와 평가용 화자를 나누고 작은 분류기를 학습했다. 코사인 점수·벡터 크기·잔여 방향 계산 가능 여부에 출처·코덱·길이의 로그값·패딩 비율까지 입력한 분류기의 클래스 균형 로그 손실은 0.054727이었다. 잔여 방향까지 추가하면 0.020767로 낮아졌다.

로그 손실은 예측 확률이 정답에서 벗어날수록 커지는 지표다. 여기서는 정상과 스푸프에 각각 50%의 가중치를 주었으며, 작을수록 좋다. 감소량은 0.033961, 개별 95% 신뢰구간은 [0.021772, 0.047048]이었다. 이 구간은 저장된 예측을 출처·화자 그룹별로 재표본화해 얻은 값으로, 분류기 재학습의 변동을 포함하지 않는다.

즉, 측정한 데이터 조건을 함께 입력한 뒤에도 잔여 방향이 예측에 도움을 주었다. 이 비교에서 크기와 조건을 사용한 것은 분석 목적이며, 기존 EBM의 탐지 점수 자체는 코사인만 사용한다. 위 수치는 실험 ①의 예측을 재사용한 결과로 별도의 독립 재현 실험이 아니며, NMI에 대한 신뢰구간도 아니다.

## 5. 해석과 한계

**방향에는 클래스 관련 신호와 데이터 조건 관련 구조가 함께 나타난다.** DF 정상 source eta²0.307754,spoof padding0.163591과21LA 정상 codec0.168577,spoof padding0.158263은 이 관찰을 구체화한다. 기존 K=4에서 codec NMI가 작았어도 원래 u에 codec 관련 구조가 없다는 뜻은 아니다.

eta²는 관찰 표본에서 조건별 평균 차이가 차지하는 분산 비율이다. 해당 조건을 제거하면 그만큼 탐지 정보가 사라진다는 인과적 기여도가 아니다. source·codec·transmission·duration·padding은 서로 연결될 수 있고,각각의 수치를 독립적인 원인 기여도로 더하지 않는다. 한 transmission 안에 codec이 하나뿐이면 eta²0은 비교 변이가 없다는 뜻이다.

기존 metadata 포함 probe에서도 방향 추가의 LL 이득이 남았다는 근거는 유효하다. 다만 같은 DF OOF 예측을 재사용했으므로 독립 재현이 아니며,측정한 조건을 선형 입력으로 넣는 것이 모든 nuisance를 통제하는 것은 아니다. 방향이 전부 shortcut이라는 결론과 방향이 전부 위조 고유 신호라는 결론을 모두 피한다.

새 strict matching은 DF27쌍/9그룹과21LA10쌍/6그룹으로 최소200쌍·10그룹을 충족하지 못했다. 조건을 같게 만든 표본에서 방향 정보가 남는지에 관한 강한 판정은 아직 불가하다. 작은 cell·적은 화자 수·class 누락은 coverage 파일에 남겨 두었다.

동일 음성의 noise/codec 개입인 R3는 별도 실행 대기/진행 단계다. 아직 결과가 없으므로 이 관찰 통계로 음향적 원인을 확정하거나 원래 attention 제거의 효과를 보고하지 않는다. 이전 K=4와 현재 전체-vector 통계는 탐색 범위가 다르며,t-SNE의 분리 정도를 정량적인 일반화 성능으로 읽지 않는다.
