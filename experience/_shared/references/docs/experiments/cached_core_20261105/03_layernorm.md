# ③ EBM 최종 LayerNorm 전후 표현의 정상·스푸프 판별 정보 비교

> **출처별 해석 보완:** DF의vcc2018 spoof는4개 화자 그룹으로,5-fold의모든test에해당조건을넣을수없다. grouped OOF비교와“모든출처×class가각fold에존재하는검증”을구분한다. 현재새P3-EBM-NoRepeat/P4에서확인한누락과보완안은[조건점검](../ebm_condition_audit_20261105.md)에있다.
> **해석 갱신: 2026-11-05 17:47 KST.** 기존 h/z 선형 probe 결과와 새 scalar+u 증분 P4를 구별한다. 신규 P4의 최종 결과는 아직 없다. 최신 통합 판정은 [방향·채널 전체 분석](../ebm_frozen_all_results_20261105.md)에 있다. 기존 실험의 수치와 그림은 해당 실행의 결과로 보존한다.

실험일: 2026년 11월 5일

## 1. 결과 요약

동일한 EBM에서 추출한 최종 LayerNorm 이전·이후의 160차원 표현에 각각 로지스틱 회귀 분류기를 학습했다. ASVspoof 2021 DF의 20,000개 발화에서 화자 그룹을 분리해 교차검증한 결과, 정규화 이전 표현을 사용한 분류기가 이후 표현을 사용한 분류기보다 낮은 log-loss를 보였다. EER은 각각 **1.4944%와 1.7000%**였다.

**이 EER은 별도로 학습한 로지스틱 분류기의 출력 점수로 계산한 값이다. 기존 EBM처럼 정상 센트로이드와의 코사인을 최종 판정 점수로 사용한 결과가 아니다.** 기존 EBM의 파라미터와 센트로이드는 고정했고, LayerNorm 제거·교체나 EBM 재학습은 수행하지 않았다.

## 2. 실험 배경과 가설

기존 EBM은 최종 발화 표현과 학습된 정상 센트로이드 사이의 코사인을 탐지 점수로 사용한다. 이 점수에 충분히 반영되지 않는 정상·스푸프 구분 신호가 있는지 조사하면서, 최종 LayerNorm 전후의 표현도 비교했다.

모델의 해당 경로는 다음과 같다.

```text
발화 → 기존 EBM의 특징 추출·집계 → 최종 Linear → h → LayerNorm → z
z → 정상 센트로이드 c와의 코사인 → 기존 EBM 탐지 점수
```

- **h**: 최종 Linear 이후, 마지막 LayerNorm 이전의 160차원 발화 표현.
- **z**: 마지막 LayerNorm 이후의 160차원 발화 표현. 코사인 계산을 위한 L2 정규화 이전 값.
- **c**: 기존 EBM이 학습한 정상 센트로이드. 아래 식에서는 길이 1로 정규화한 값을 뜻한다.

LayerNorm은 한 발화의 160개 좌표에서 평균을 빼고 표준편차에 해당하는 값으로 나눈 뒤, 학습한 좌표별 배율과 편향을 적용한다.

\[
z_j=\gamma_j\frac{h_j-\mu_h}{\sqrt{\sigma_h^2+10^{-12}}}+\beta_j.
\]

여기서 평균과 표준편차는 **발화 임베딩의 좌표 통계**이며, 원음의 평균이나 음량을 뜻하지 않는다. 이 변환은 발화별 좌표 평균을 제거하고 크기 차이를 강하게 정규화하므로, h의 통계나 좌표에 있던 판별 신호가 z에서는 같은 분류기로 읽기 어려워질 가능성을 생각할 수 있다.

이에 따라 **“같은 수의 좌표와 같은 종류의 분류기를 사용할 때, h가 z보다 정상·스푸프를 더 잘 구분하게 하는가?”**를 검증했다. LayerNorm의 문제가 사전에 확인돼서 시작한 실험은 아니며, 모델 구조에 근거한 탐색적 가설이다.

## 3. 데이터와 비교군 구성

### 데이터와 고정한 부분

ASVspoof 2021 DF의 고정 표본 20,000개를 사용했다. 정상 발화는 2,000개, 스푸프 발화는 18,000개다. 기준 모델은 batch size 160으로 50 epoch 학습한 기존 EBM이다.

각 발화의 **동일한 오디오 구간을 한 번 처리하는 과정에서 저장한 h와 z**를 사용했다. 이번 비교를 위해 음성을 다시 처리하거나 임베딩을 다시 추출하지 않았다. EBM과 센트로이드는 변경하지 않고, 저장된 표현을 입력받는 로지스틱 분류기만 별도로 학습했다.

### 모든 비교군에 공통으로 넣은 8차원 입력

각 비교군은 기존 점수와 관련된 정보를 공통으로 받고, 여기에 추가하는 표현만 달리했다. 공통 입력은 다음과 같다.

| 구성 요소 | 계산 방법 | 차원 수 |
| --- | --- | ---: |
| 기존 EBM 코사인 점수의 변환 | s = cos(z, c)에 3차 spline 적용. 학습 부분의 분위수로 5개 기준점을 정하고, 마지막 기저 하나를 제외한 6개 값을 사용 | 6 |
| 최종 표현의 크기 | log(‖z‖₂) | 1 |
| 센트로이드 직교 성분의 유효 여부 | x = z/‖z‖₂에 대해 ‖x − (x·c)c‖₂ ≥ 10⁻⁴이면 1, 아니면 0 | 1 |
| **합계** | | **8** |

Spline은 코사인과 정답 사이의 비선형 관계를 읽도록 점수 하나를 여러 기저 값으로 변환한다. 마지막 지시자는 다른 방향 정보 진단과 공통으로 사용한 입력이며, 별도의 정답 정보는 포함하지 않는다.

**이 8차원 입력도 기존 EBM의 원래 판정 방식과는 다르다.** 기존 EBM은 코사인 하나를 점수로 사용하지만, 여기서는 코사인의 변환값·벡터 크기·유효 여부를 새 분류기의 입력으로 사용했다.

### 네 비교군

| 비교군 | 로지스틱 분류기에 넣은 정보 | 전체 입력 차원 | 비교 목적 |
| --- | --- | ---: | --- |
| 공통 입력만 | 위의 8차원 입력 | 8 | 표현 좌표를 추가하지 않은 기준 |
| 정규화 이후 표현 추가 | 공통 입력 + z의 160개 좌표 | 168 | 최종 표현의 좌표를 추가했을 때의 성능 |
| 정규화 이전 표현 추가 | 공통 입력 + h의 160개 좌표 | 168 | 같은 수의 좌표를 h로 바꿨을 때의 성능 |
| 정규화 이전 통계 추가 | 공통 입력 + mean(h) + log(std(h)) | 10 | 발화별 평균·크기 통계만 추가했을 때의 성능 |

주 비교는 **168차원인 두 비교군**, 즉 정규화 이후 표현 추가와 정규화 이전 표현 추가다. 공통 입력은 두 경우 모두 z에서 계산한 동일한 값이다. h의 평균·표준편차는 한 발화의 160개 좌표에서 계산하며, 분산 계산의 분모는 좌표 수인 160을 사용했다.

각 입력의 모든 열은 학습 부분에서 계산한 열별 평균·표준편차로 표준화한 뒤 분류기에 넣었다. 이 전처리는 여러 학습 발화에서 각 좌표의 분포를 맞추는 과정으로, 한 발화 안의 좌표를 정규화하는 모델 내부 LayerNorm과 다르다.

## 4. 분류기 학습과 평가 방법

### 화자 그룹을 분리한 교차검증

데이터 출처와 화자 식별자를 함께 사용한 93개 그룹을 기준으로 바깥쪽 5분할 교차검증을 수행했다. 같은 출처의 같은 화자 그룹이 학습과 평가에 함께 들어가지 않도록 했다.

1. 5개 부분 중 4개로 분류기를 학습하고, 남은 1개를 평가한다.
2. 각 학습 부분 안에서 다시 3분할 교차검증을 수행해 L2 규제 강도를 선택한다. 후보는 C = [0.01, 0.1, 1, 10]이며, 클래스 균형 log-loss가 가장 낮은 값을 고른다.
3. 선택한 설정으로 바깥쪽 학습 부분 전체에서 분류기를 다시 학습하고, 바깥쪽 평가 부분을 예측한다.
4. 다섯 번 반복해 모든 발화에 대해 해당 화자 그룹을 학습에 사용하지 않은 예측을 하나씩 얻고, 이 예측들을 합쳐 최종 지표를 계산한다.

네 비교군의 분류기는 **각각 따로 학습**했다. 같은 분할과 규제 후보·선택 규칙을 사용하지만, 선택된 EBM-FullContext와 학습된 계수는 비교군마다 다를 수 있다. Spline 기준점과 입력 표준화의 평균·표준편차도 해당 학습 부분에서만 계산했다. 분류기 학습에는 클래스별 총 가중치가 같아지도록 가중치를 적용했다.

이는 **DF 데이터 내부에서 학습하고 화자 그룹을 분리해 평가한 결과**다. ASVspoof 2019 LA에서 새 분류기를 학습한 뒤 2021 DF로 전이한 평가가 아니다.

### EER에 사용한 점수

표준화한 입력 벡터를 q라고 할 때, 각 로지스틱 분류기는 다음 값을 출력한다.

\[
a=w^\top q+b,\qquad p(\mathrm{normal}\mid q)=\operatorname{sigmoid}(a).
\]

분류기 학습에 사용하지 않은 평가 부분에서 얻은 **로지스틱 분류기의 출력 점수 a**를 합쳐 EER과 AUROC를 계산했다. 높은 점수는 정상을 뜻한다. EER은 임계값을 변화시켜 정상 오거부율과 스푸프 오수락률이 같아지는 지점을 선형 보간해 구했다. 확률 p는 a의 단조변환이므로 동일한 순위를 갖는다.

기존 EBM과 이번 평가의 차이는 다음과 같다.

```text
기존 EBM 평가:
z → 정상 센트로이드와의 코사인 → EER

이번 표현 비교:
공통 입력 또는 공통 입력 + 표현·통계
→ 별도로 학습한 로지스틱 분류기의 출력 점수 → EER
```

센트로이드는 공통 입력의 코사인과 직교 성분을 계산할 때 사용했다. **h용 센트로이드를 새로 추정하거나, z 공간에서 학습한 센트로이드를 h에 그대로 적용한 코사인을 평가하지 않았다.**

### 주 평가지표와 불확실성

주 평가지표는 정상과 스푸프에 각각 50% 가중치를 부여한 log-loss다. 정상 확률을 p라고 하면 다음과 같이 계산한다.

\[
L=-\tfrac12\operatorname{mean}_{\mathrm{normal}}\log p
  -\tfrac12\operatorname{mean}_{\mathrm{spoof}}\log(1-p).
\]

EER과 AUROC는 보조 지표로 보고했다. 주 비교의 효과는 **정규화 이후 표현 추가 모델의 log-loss에서 정규화 이전 표현 추가 모델의 log-loss를 뺀 값**으로 정의했다. 양수이면 정규화 이전 표현을 사용한 모델이 좋다.

같은 출처·화자 그룹을 함께 재표집하는 paired bootstrap을 2,000회 수행해 이 차이의 개별 95% 신뢰구간을 계산했다. 재표집 때는 저장된 평가 예측을 사용했고, 분류기를 다시 학습하지 않았다. 이 구간은 EER 차이의 신뢰구간이 아니다.

## 5. 결과

**아래 네 행 모두 별도로 학습한 로지스틱 분류기의 성능이다. 원래 센트로이드 코사인만 사용한 EBM 성능은 이 표에 포함하지 않았다.**

| 로지스틱 분류기의 입력 | 입력 차원 | 클래스 균형 log-loss ↓ | EER (%) ↓ | AUROC ↑ |
| --- | ---: | ---: | ---: | ---: |
| 공통 입력만 | 8 | 0.098882 | 3.5056 | 0.994842 |
| 공통 입력 + 정규화 이후 z | 168 | 0.064016 | 1.7000 | 0.995917 |
| 공통 입력 + 정규화 이전 h | 168 | **0.040671** | **1.4944** | **0.999046** |
| 공통 입력 + h의 평균·log(표준편차) | 10 | 0.091780 | 3.2444 | 0.994662 |

정규화 이전 표현을 사용한 모델의 log-loss는 이후 표현을 사용한 모델보다 **0.023345 낮았고**, 차이의 개별 95% 신뢰구간은 **[0.010456, 0.042250]**이었다. 바깥쪽 5개 평가 부분 모두에서 정규화 이전 표현을 사용한 모델의 log-loss가 낮았다.

EER 차이는 **0.2056%p**였다. 이는 합쳐진 평가 예측에서 관찰한 차이이며, EER 차이에 대한 별도의 신뢰구간이나 유의성 검정은 수행하지 않았다.

## 6. 해석과 한계

**기존 DF 내부에서 h를 사용한 동일 계열 probe가 z를 사용한 probe보다 LL이 낮았다.** 이는 정한 분류기의 정보 접근성 차이를 조사할 근거다. EER1.4944%는 h와 기존 centroid의 cosine 성능이 아니라 별도 로지스틱 probe의 점수다.

z는 h의 결정적 변환이지만, 한 선형 probe의 성능 차이만으로 어떤 정보가 얼마나 사라졌는지 또는 LayerNorm이 기존 탐지 오류를 일으켰는지 판정할 수 없다. 좌표 배치·scale·규제·수치 조건이 같은 정보의 읽기 쉬운 정도를 바꿀 수 있다.

LayerNorm은 발화 내부의 공통 shift에 정확히 불변이다. 양의 scale에는 epsilon>0일 때 일반적으로 정확히 불변하지 않다. 여기 epsilon은1e-12이고 관찰 h분산은 훨씬 크므로 scale 영향이 강하게 정규화되는 상황이다. “평균과 분산 정보가 전부 수학적으로 완전히 소실됐다”는 표현은 쓰지 않는다. 이 통계는 원음의 음량이 아니라 최종160좌표의 통계다.

기존 scalar+h-stat가 전체 h보다 이득이 작았다는 사실만으로 h/z 차이를 두 통계가 설명하거나 설명하지 못한다고 단정할 수 없다. 옛 실험은 scalar+u에 h-stat/h를 추가하고 같은 차원의 noise와 비교한 대조가 아니다.

새 P4는 **scalar+u**를 공통 기준으로 mean(h)·log(std(h)) 두 열 또는 h160을 추가하고,각각 noise2/noise160과 비교한다. DF/21LA 각2만 개에 별도5×3 grouped CV를 쓰며 scaler·ridge·epoch를 fold 안에서만 정한다. 현재 전체 실행·OOF·검수가 끝나지 않았으므로 이 증분의 성공 여부와21LA 재현은 미정이다.

보고 가능한 결론은 “옛 DF 내부 probe에서 h의 접근성이 더 좋았다”다. 보고할 수 없는 결론은 “LayerNorm 제거로 기존 EBM이 개선됐다”,“정규화가 나빠진 원인이다”,“새 attention이 이 정보를 이용할 것이다”다. 후자는 공동 학습 또는 적절한 통제 개입이 필요하다.

옛 LL 개선의 개별95% 구간과 EER 차이의 추론을 구분한다. 옛 EER0.2056pp 차이에 별도 EER CI를 계산한 것은 아니다. 이미 관찰한 하나의 DF 표본·checkpoint와 저장 OOF 예측에 조건부인 bootstrap이며,원발화 family와 전체 재학습 불확실성은 미해결이다.
