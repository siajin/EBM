## 1. 가설

**음성을 나타내는 특징 벡터에는 기존 탐지 점수와 벡터 크기만으로는 읽어 내지 못하는 정상·스푸프 구분 정보가 남아 있을 수 있다.**

모델은 음성 한 개를 160개의 숫자로 표현한다. 이 숫자들을 묶은 것이 특징 벡터다. 기존 탐지 점수는 이 벡터가 학습된 기준 벡터와 얼마나 비슷한 방향을 향하는지 나타내는 코사인 유사도다. 벡터 길이를 1로 맞춘 뒤 내적해 계산하므로, 특징 벡터의 절대 크기는 점수에 별도로 반영되지 않는다.

같은 코사인 점수를 갖는 두 벡터도 기준 벡터 주위에서 서로 다른 방향을 향할 수 있다. 이번 실험은 **기준 벡터를 향하는 성분을 뺀 뒤 남는 방향**에 추가 판별 정보가 있는지 확인했다. 아래에서는 이를 ‘잔여 방향’이라고 부른다.

가설을 확인하려면 코사인 점수와 크기만 입력했을 때보다 잔여 방향까지 입력했을 때 학습에 포함되지 않은 화자의 예측이 좋아져야 한다. 같은 수의 무작위 숫자를 추가하는 경우와도 비교해, 단순히 입력 수가 늘어나서 생긴 변화인지 확인했다. 음성의 출처·압축 방식·길이·입력 길이를 맞추기 위해 채운 비율을 함께 입력한 경우도 비교했다.

## 2. 실험

두 가지 비교를 수행했다.

1. **학습용 화자와 평가용 화자를 나눈 분류 실험:** 같은 종류의 작은 분류기에 코사인 점수·크기, 잔여 방향, 무작위 잡음, 데이터 조건을 서로 다르게 조합해 입력했다. 어떤 입력이 추가될 때 정상·스푸프 구분이 좋아지는지 비교했다.
2. **점수와 크기가 비슷한 정상·스푸프 쌍의 비교:** 같은 출처와 압축 방식에서 코사인 점수와 벡터 크기가 가까운 두 음성을 짝지었다. 첫 번째 비교에서 각 음성을 학습에 넣지 않고 얻은 예측을 사용해, 구분이 어려운 표본에서도 잔여 방향의 이득이 나타나는지 확인했다.

기존 EBM의 가중치는 고정했다. 새 음성 특징을 추출하거나 EBM을 다시 학습하지 않았으며, 저장된 특징을 읽는 작은 분류기만 CPU에서 학습했다.

## 3. 수행 방식

### 데이터와 입력 정보

ASVspoof 2021의 음성 위조 탐지 평가 데이터인 DF(DeepFake)에서 미리 고정한 20,000개 표본을 사용했다. 정상 2,000개, 스푸프 18,000개이며, DF 전체 평가 데이터는 아니다. 정답은 정상 1, 스푸프 0으로 표시했다.

음성별로 저장된 160차원 특징 벡터를 z, EBM이 학습한 기준 벡터를 c라고 표기한다. c는 모델의 학습된 중심 벡터(centroid)이며, 이번 DF 표본에서 새로 계산한 평균이 아니다. 두 벡터의 길이를 각각 1로 맞춘 것을 ẑ, ĉ라고 할 때 입력을 다음과 같이 만들었다.

    s = ẑ · ĉ          기존 코사인 탐지 점수
    r = ẑ - s ĉ        기준 벡터에 수직으로 남는 성분
    u = r / ||r||       남는 성분의 길이를 1로 맞춘 잔여 방향

||r||은 벡터 r의 길이다. ẑ와 ĉ의 길이가 1이므로 ||r||은 코사인 점수 s로 결정된다. 따라서 잔여 성분의 길이를 새로운 정보로 세지 않고 방향 u를 조사했다. ||r||이 0.0001 이상인지를 나타내는 값도 입력해, 잔여 방향을 안정적으로 계산할 수 있는지 표시했다.

비교용 기본 분류기에는 **코사인 점수의 곡선형 변환(spline_5), 특징 벡터 크기의 로그값 log(||z||), 잔여 방향 계산 가능 여부**를 입력했다. 곡선형 변환은 점수와 정답 사이의 관계를 직선 하나보다 유연하게 읽도록 하기 위한 처리다. 이후 표에서 ‘점수·크기’는 이 세 입력을 뜻한다.

기존 EBM은 코사인 점수만 사용한다. 위 비교용 분류기는 크기를 알고도 방향이 추가로 도움이 되는지 확인하기 위해 별도로 학습한 것이다.

### 분류기의 학습과 평가

출처와 화자 식별자의 조합으로 만든 93개 그룹을 5개 묶음으로 나눴다. 매번 4개 묶음에서 학습하고 나머지 1개에서 평가하는 교차검증을 수행했다. 같은 출처·화자 그룹은 학습과 평가에 동시에 들어가지 않는다.

각 학습 부분을 다시 3개 묶음으로 나누어 분류기 설정을 선택했다. 분류기는 가중치가 지나치게 커지는 것을 억제하는 L2 규제를 적용한 로지스틱 회귀다. 규제 강도의 역수 C는 [0.01, 0.1, 1, 10] 중 클래스 균형 로그 손실이 가장 작은 값으로 정했다. 코사인 점수의 곡선형 변환, 수치 입력의 척도 조정, 범주별 0/1 변환도 해당 학습 부분에서만 정했다.

비교한 입력 조합은 다섯 가지다.

- 점수·크기
- 점수·크기 + 무작위 잡음
- 점수·크기 + 잔여 방향
- 점수·크기 + 데이터 조건
- 점수·크기 + 데이터 조건 + 잔여 방향

데이터 조건은 음성의 출처, 코덱(음성을 압축·복원하는 방식), 발화 길이의 로그값, 패딩 비율이다. 패딩 비율은 모델의 고정 입력 길이를 맞추기 위해 원래 음성 외에 채워 넣은 부분의 비율이다. 출처와 코덱은 각 범주에 해당하는지를 0/1로 표시했다.

무작위 잡음은 음성 식별자별로 고정한 160차원 정규분포 난수를 기준 벡터에 수직으로 투영한 뒤 길이를 1로 맞춰 만들었다. 이는 입력 수 증가에 대한 비교군이다. 실제 잔여 방향과 분포까지 같은 비교군은 아니다.

각 음성에 대해 그 음성을 학습에 포함하지 않은 분류기의 예측을 모아 평가했다. 주 지표는 **클래스 균형 로그 손실**이다. 예측 확률이 정답에서 벗어날수록 커지는 손실을 정상·스푸프별로 평균 낸 뒤 각각 50%씩 반영하며, 작을수록 좋다. 보조 지표는 다음과 같다.

- **EER(동일 오류율):** 정상 음성을 스푸프로 거부하는 비율과 스푸프를 정상으로 통과시키는 비율이 같아지는 지점의 오류율이다. 작을수록 좋다.
- **AUROC(ROC 곡선 아래 면적):** 판정 기준을 바꾸어 가며 두 클래스를 얼마나 잘 구분하는지 요약한다. 클수록 좋다.

### 점수·크기가 가까운 음성의 짝짓기와 신뢰구간

같은 출처와 코덱 안에서 코사인 점수 차이가 0.01 이하이고 벡터 크기의 로그값 차이가 0.002 이하인 정상·스푸프를 중복 없이 짝지었다. 정상 음성 식별자의 SHA256 해시값 순으로 진행하고, 두 차이를 각각의 허용 폭으로 나눈 뒤 제곱해 더한 값이 가장 작은 스푸프를 골랐다. 더 좁은 허용 폭 0.005/0.001과 더 넓은 허용 폭 0.02/0.004에서도 결과를 확인했다.

짝지은 음성에는 앞서 저장한 평가용 예측을 그대로 사용했다. 이 표본으로 분류기나 설정을 다시 선택하지 않았다.

신뢰구간은 출처·화자 그룹을 단위로 복원 추출하는 부트스트랩을 2,000회 수행해 계산했다. 비교하는 두 방법에 같은 재표본을 적용하는 대응 비교다. 각 비교의 개별 95% 신뢰구간이며, 모든 비교를 동시에 보장하는 구간은 아니다. 저장된 예측을 재표본화했으므로 분류기를 다시 학습할 때의 변동은 포함하지 않는다.

허용 폭을 좁히면 72쌍, 넓히면 139쌍이었고, 두 경우에도 방향 추가가 점수·크기만 사용하거나 잡음을 추가한 경우보다 좋았다. 같은 화자라는 조건까지 요구하면 18쌍·7그룹만 남았다.

## 5. 해석과 한계

**현재 z에서 잔여 방향 관련 신호를 읽을 수 있다는 기존 DF 내부 근거는 유효하다. 그러나 그 신호를 T에서 학습한 readout으로 사용해 평가셋의 EER를 개선한다는 근거는 얻지 못했다.** 새 선형 전이는 LL을 작게 줄였으므로 “방향을 사용해도 아무 효과가 없다”는 표현도 피한다.

기존106쌍은 같은 source×codec을 요구했지만 같은 화자를 요구하지 않았다. 새 F2는 DF의 source×speaker×codec,21LA의 speaker×codec×transmission을 맞추고 caliper0.02/0.002를 적용했다. 옛106쌍과 새27쌍은 같은 실험의 모순된 수치가 아니다. 새 넓은 caliper 민감도에서도 DF58쌍/15그룹,21LA21쌍/14그룹으로200쌍에 못 미쳤다. 결론은 표본 부족이지 방향 정보 부재가 아니다.

MMD²와 평균 방향 각도가 0보다 크다는 관찰만으로 조건부 방향 차이가 증명되지 않는다. 근사 matching이며,biased MMD의 bootstrap 구간은 동일분포 null 검정이 아니다. 방향의 평균 차이·분산 구조는 작은 매칭 표본의 기술 통계로 한정한다.

u는 z의 결정적 변환이다. 추가 입력에서 더 잘 읽힌다는 것은 정한 probe의 표현 접근성에 관한 결과이며, 정보량 생성이나 정확한 조건부 상호정보량의 측정이 아니다. metadata 대조가 있어도 측정하지 않은 조건·비선형 교란과 원발화 family 의존성이 남는다.

원래 EBM은 centroid 각도를 이용하고 채널 혼합·layer/time attention도 학습한다. “방향을 전혀 사용하지 않는다”보다 “최종 scalar에 남지 않은 잔여 방위를 이 readout이 활용할 수 있는가”가 정확한 질문이다. 새 공동 학습 attention/방향 loss의 효과는 이번 동결 실험으로 확정하지 않는다.

기존2,000회 개별95% CI와 새10,000회 전이 CI는 서로 다른 fit·선택에 조건부다. 기존 DF1.20%/0.60%를 T→DF 또는 새 EBM의 일반화 성능으로 제시하지 않는다. 새 P3-B가 끝나면 같은 모델 계열의 내부/전이 차이를 별도로 판단한다.
