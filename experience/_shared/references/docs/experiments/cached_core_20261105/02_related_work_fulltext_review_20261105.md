# EBM 최종 임베딩의 채널 선택 실험: 관련 논문 본문 검토

> **해석 갱신: 2026-11-05 17:47 KST.** 문헌별 원문 보고는 기존 검토 범위로 보존한다. 우리 실험의 후속 결과·판정·미완료 목록만 최신화했으며 이번에 새 문헌 검색을 수행하지 않았다. 최신 통합 판정은 [방향·채널 전체 분석](../ebm_frozen_all_results_20261105.md)에 있다. 기존 실험의 수치와 그림은 해당 실행의 결과로 보존한다.

검토일: 2026-11-05. 대상은 **학습이 끝난 EBM의 최종 160차원 표현과 정상 센트로이드에서 같은 좌표를 선택하고, 선택한 공간에서 다시 정규화하여 코사인 점수를 계산한 실험**이다. 새 모델 학습·새 분류기 학습·원음 재추론 없이 수행한 실험이라는 조건을 기준으로 문헌을 비교했다.

## 1. 먼저 답할 수 있는 것

**관련 연구는 있다.** 학습 후 일부 활성값이나 연결을 제외하여 탐지를 개선한 DICE·ASH, 음성 딥페이크에서 소수 특징을 선택한 연구, 특징의 개별 Fisher 순위와 조합의 유용성이 다를 수 있음을 다룬 연구가 직접 관련된다. 저차원 표현과 군집의 형태를 해석할 때는 Matryoshka Representation Learning과 Neural Collapse도 참고할 만하다.

그러나 검토한 문헌에서 **고정 EBM의 학습 데이터 Fisher 하위 좌표만 남기고, 기존 센트로이드에도 같은 마스크를 적용해 재정규화 코사인을 계산한 뒤 160→2→1차원까지 비교한 동일 실험**은 찾지 못했다. 이것은 이번 검색·열람 범위 안의 판단이며, 세계 최초라는 확인은 아니다.

현재 가장 근거가 강한 결론은 다음과 같다.

> 한 고정 EBM에서, 최종 표현의 일부 좌표만 사용해 코사인을 다시 계산해도 DF 표본의 EER 부근에서는 판별력이 유지되었다. 다만 전체 ROC와 다른 데이터 조건에서는 손익이 달랐다. 이는 표현의 일부 좌표와 코사인 점수의 관계를 보여주는 탐색 결과이며, 전체 정보가 두 좌표에만 있다는 증거는 아니다.

## 2. 문헌과 비교하기 전에 고정할 실험 사실

자세한 실험은 [채널 제거 실험 보고서](02_channel_ablation.md)에 기록되어 있다.

| 항목 | 이번 실험에서 실제로 한 일 |
|---|---|
| 표현 | 한 고정 EBM이 산출한 최종 LayerNorm 이후 160차원 벡터 z |
| 원래 점수 | 정상 센트로이드 c와의 코사인. 벡터 크기를 별도 입력으로 사용하지 않음 |
| 좌표 순위 | 학습 데이터에서 정상과 각 학습 공격 사이의 단변량 Fisher 점수를 계산하고 공격별로 동일 가중 평균 |
| 좋은 EER를 보인 두 좌표 | **Fisher 상위가 아니라 하위 두 좌표**, 0부터 센 번호 113·95 |
| 변경 | z와 c에서 동일한 좌표 집합 K를 선택한 뒤 각각 다시 L2 정규화 |
| 유지 | EBM 가중치·센트로이드 값·코사인 점수의 형태 |
| 추가 학습 | 없음. 새로운 분류기나 게이트도 없음 |
| 평가 | 2021 DF에서 점수와 무관하게 선정한 고정 20,000개 표본. 전체 공식 평가셋과 구별 |
| 탐색 이력 | 같은 DF 결과를 보며 유지 개수를 순차 확대해서 비교한 탐색 실험 |

점수는 다음과 같다.

\[
s_K(z,c)=\frac{\sum_{j\in K}z_jc_j}
{\sqrt{\sum_{j\in K}z_j^2}\sqrt{\sum_{j\in K}c_j^2}}.
\]

따라서 채널 제거는 분자의 항만 없애는 연산이 아니다. **정규화에 사용하는 길이도 바뀌므로 각도와 샘플의 점수 순서가 달라질 수 있다.** 원래 표현 전체의 정보량과 이 특정 점수의 성능은 구분해야 한다.

| 조건 | DF EER (%) | DF AUROC |
|---|---:|---:|
| 전체 160개 | 3.3500 | 0.995943 |
| Fisher 하위 30개 | 3.0000 | 0.996256 |
| Fisher 하위 20개 | 2.9500 | 0.996227 |
| Fisher 하위 10개 | 2.9444 | 0.996202 |
| Fisher 하위 5개 | 2.9500 | 0.996048 |
| Fisher 하위 2개 | 2.9222 | 0.987659 |
| Fisher 하위 1개 | 4.3459 | 0.967472 |

전체 유지 수를 확인하면 Fisher 하위 70·60·50·40·30·20·10·5개는 EER와 AUROC가 함께 전체 160개보다 좋은 점추정치를 보였다. 초기 152개도 아주 작은 AUROC 상승이 있었다. 30개는 이 Fisher 하위 유지 경로에서 AUROC가 가장 높았다. 아래의 ‘두 좌표에서는 AUROC가 나빠졌다’는 설명은 두 좌표 조건에 관한 것이며, 모든 축소 조건에 해당하지 않는다. AUROC 차이의 통계적 유의성은 별도로 검증하지 않았다.

하위 2개와 전체의 EER 차이는 −0.4278%p이며, source×speaker 93그룹을 이용한 paired bootstrap 2,000회의 개별 95% 구간은 약 [−0.7991, +0.0693]%p로 0을 포함한다. 이 구간은 반복 탐색·다중 비교·미해결 원발화 계열 의존성을 해결한 구간이 아니다.

DF ROC에서 정상 오거부를 1% 이하로 제한하면 스푸프 통과는 전체 6.1056%, 두 좌표 15.8111%였고, 3% 이하에서는 각각 3.5111%, 2.8889%였다. **두 좌표가 모든 임계값에서 더 좋은 것은 아니다.**

아래의 ‘가설’은 각 논문의 연구 질문을 이번 실험과 연결해 요약한 것이다. 모든 논문이 동일한 형식의 가설 검정을 수행했다는 뜻은 아니다. 수치는 해당 논문 내부의 비교이며, 서로 다른 데이터·분할·과업의 수치를 우리 EER와 직접 비교하지 않는다.

## 4. 논문별 검토: 가설 → 실험 → 방식 → 결과 → 해석

### 4.1 EBM 원 논문 — Kim 등, Interspeech 2025

**문헌:** [Enhancing Audio Deepfake Detection by Improving Representation Similarity of Bonafide Speech](https://www.isca-archive.org/interspeech_2025/kim25g_interspeech.pdf).

1. **가설:** 정상 음성 표현을 더 응집시키고 스푸프와의 각도상 분리를 강화하면 미지 공격 탐지가 좋아진다.
2. **실험:** OC-Softmax, EOC-S, OC-Softmax+BPL, EOC-S+BPL을 각각 학습해 비교했다.
3. **방식:** 정상만 센트로이드 업데이트에 기여하게 하고, 정상 쌍을 가깝게 하는 손실을 결합했다. 최종 160차원 표현에서 코사인으로 판정한다. §2–5, 수식 1–11, Tables 1–2와 Fig. 4를 확인했다.
4. **결과:** Table 2의 2021 DF EER는 OC 2.43%, EOC-S 2.12%, OC+BPL 1.93%, EBM 1.89%다. Fig. 4는 정상 코사인 점수가 1 부근에 더 모이는 모습을 제시한다.
5. **해석:** 정상의 응집과 점수 분포를 설명하는 직접 배경이다. 그러나 **160개 좌표가 모두 필요하다는 실험은 하지 않았다.** 이번 실험은 학습된 표현의 점수 의존성을 추가로 조사한다. 논문 모델과 우리 체크포인트·학습 조건·평가 표본이 달라 1.89%와 3.35%를 재현 성공·실패로 바로 비교할 수 없다.

### 4.2 EBM 확장 논문 — Kim 등, IEEE Access 2026

**문헌:** [Comprehensive Validation of Bridge Module and EBM Loss for One-Class Audio Deepfake Detection](https://doi.org/10.1109/ACCESS.2026.3680160). [저자 소속기관의 출판 기록](https://pure.uos.ac.kr/en/publications/comprehensive-validation-of-bridge-module-and-ebm-loss-for-one-cl/).

1. **가설:** EBM의 이점이 증강·손실 설정·발화 길이·frontend/backbone을 바꿔도 유지되는가?
2. **실험:** 네 축의 설정 변화와 모델 간 적용을 검증했다.
3. **방식:** §IV-4.0375초 상한 비반복 학습은 projection widths를 (128, 128, **160**)으로 모든 backbone에 고정했다고 명시한다. §III의 손실·정규화 설명, §V 전체 실험과 §VI 결론을 확인했다.
4. **결과:** §V-E는 2021 DF EER 1.85%를 보고한다. §V-G와 Fig. 5는 OC baseline과 EBM의 2021 DF **t-SNE 군집 그림을 이미 제시한다.**
5. **해석:** “EBM의 군집을 시각화했다” 자체는 새로운 기여로 삼기 어렵다. 반면 이 논문도 최종 채널 개수 축소를 검증하지 않는다. 우리 차별점은 **고정 표현·센트로이드에서 같은 마스크로 코사인을 다시 계산했을 때의 성능과 오류 관계**에 있다. 논문의 일반화 설명을 두 좌표의 충분성 증명으로 사용하면 안 된다.

### 4.3 OC-Softmax — Zhang·Jiang·Duan, IEEE SPL 2021

**문헌:** [One-class Learning Towards Synthetic Voice Spoofing Detection](https://arxiv.org/abs/2010.13995).

1. **가설:** 스푸프의 미래 분포 전체를 학습하기보다 정상 표현을 조밀하게 만들면 미지 공격에 대응하기 쉽다.
2. **실험:** 같은 계열 모델에서 Softmax·AM-Softmax·OC-Softmax를 비교하고 공격별 성능과 표현을 분석했다.
3. **방식:** LFCC와 ResNet 기반 256차원 표현에 정상·스푸프별 다른 각도 마진을 준다. 평가 점수는 정상 중심과의 코사인이다. 수식 1–3, Tables II–IV, Fig. 2 확인.
4. **결과:** ASVspoof **2019 LA** 평가에서 OC-Softmax EER 2.19%를 보고한다. Fig. 2에 dev/eval의 t-SNE와 PCA가 모두 있다. 미지 스푸프가 학습 스푸프와 다른 군집에 나타나는 점도 논의한다.
5. **해석:** 코사인 점수와 정상 중심 구조를 이해하는 출발점이다. 단일 코사인 점수를 쓰는 것과 원래 표현 자체가 한두 차원이라는 것은 별개다. 출력 좌표 선택 실험은 없다.

### 4.4 ACS — Kim·Jang·Kim, Interspeech 2024

**문헌:** [One-Class Learning with Adaptive Centroid Shift for Audio Deepfake Detection](https://www.isca-archive.org/interspeech_2024/kim24b_interspeech.pdf).

1. **가설:** 정상 데이터로 적응시키는 중심을 사용하면 정상·스푸프의 분포 불일치에 더 강해진다.
2. **실험:** 중심을 고정·학습·부분 고정·누적 이동하는 방식과 손실을 비교했다.
3. **방식:** XLS-R을 미세조정하고 정상 표현의 누적 평균으로 중심을 이동시킨다. 정상 코사인을 높이고 스푸프 코사인을 낮춘다. 수식 1–6, Tables 1–4와 Fig. 3 확인.
4. **결과:** 2021 DF에서 중심 방식별 EER가 고정 3.13%, 학습 2.52%, 부분 고정 2.44%, ACS 2.19%다. Fig. 3은 2021 LA의 t-SNE 비교다.
5. **해석:** 같은 코사인이라도 **표현 학습과 중심을 어떻게 정하는지**가 중요함을 보여준다. 이번에는 표현과 중심을 고정하고 좌표만 선택했으므로, ACS의 성능 향상 원인과 동일시할 수 없다.

### 4.5 Generalized Fisher Score — Gu·Li·Han, UAI 2011

**문헌:** [Generalized Fisher Score for Feature Selection](https://web.cs.ucla.edu/~qgu/pdf/uai11.pdf). [학회 논문 기록](https://proceedings.mlr.press/r9/gu11a.html).

1. **가설:** 특징별 Fisher 점수를 독립적으로 매기면 특징 간 상관과 조합 효과를 놓친다.
2. **실험:** 단변량 Fisher 선택과 특징 집합을 공동 선택하는 방법을 여러 데이터에서 비교했다.
3. **방식:** 정규화된 판별 목적의 하한을 최적화하여 특징 집합을 고르고, 1-NN 등으로 평가한다. §1–3의 논의·최적화·Algorithm 1과 후속 실험 확인.
4. **결과:** 논문은 단독 점수가 낮아도 함께 유용할 수 있고, 점수가 높은 특징끼리는 중복될 수 있음을 설명한다. USPS의 10개 특징 예에서는 제안법이 약 80%, 단변량 Fisher가 약 50% 정확도다.
5. **해석:** **Fisher 하위 = 모델에 불필요한 채널**이라는 해석을 피해야 하는 가장 직접적인 근거다. 우리 순위는 학습 데이터에서의 개별 평균·분산 차이이며, 고정 코사인의 기여도나 DF 일반화 중요도와 같지 않다. 이 논문은 그 한계를 뒷받침하지만 우리 두 좌표의 성공 원인까지 밝혀주지는 않는다.

### 4.6 DICE — Sun·Li, ECCV 2022

**문헌:** [DICE: Leveraging Sparsification for Out-of-Distribution Detection](https://arxiv.org/abs/2111.09805).

1. **가설:** 학습된 모델의 일부 연결이 OOD 점수에 불필요한 변동을 더하므로 선택적으로 제외하면 탐지가 좋아진다.
2. **실험:** 평균 기여도 기반 선택을 무작위·가중치 크기·상위/하위 선택과 비교하고 희소도 및 분산을 분석했다.
3. **방식:** 학습 ID 데이터의 평균 w×h 기여도가 큰 연결을 남긴다. 고정 선형 head의 마스크된 로짓에서 log-sum-exp 에너지 점수를 계산한다. 전체 본문과 부록 A–G, 특히 §5–6과 Table 4 확인.
4. **결과:** Table 4의 CIFAR-10/100 FPR95는 상위 선택 20.83/49.72%, 하위 선택 91.87/99.70%다. **하위를 남기는 방식은 실패했다.** 극단적인 희소도에서는 성능이 다시 나빠진다.
5. **해석:** “모든 연결을 사용하지 않아도 탐지가 개선될 수 있다”는 강한 선행연구다. 그러나 DICE의 기여도 상위와 우리의 Fisher 하위는 다른 기준이다. 선형 합의 분산 분석을, 상관된 signed LayerNorm 표현과 재정규화 코사인에 그대로 적용할 수 없다. 최적 희소도에는 별도 검증도 사용하므로 검증 없이 최적 채널 수를 고를 근거가 아니다.

### 4.7 ASH — Djurisic 등, ICLR 2023

**문헌:** [Extremely Simple Activation Shaping for Out-of-Distribution Detection](https://arxiv.org/abs/2209.09858).

1. **가설:** 재학습 없이 후기 층의 활성값을 제거·변형하는 것만으로 ID/OOD 분리가 좋아질 수 있는가?
2. **실험:** 제거만 하는 ASH-P, 남은 값을 동일하게 만드는 ASH-4.0375초 상한 비반복 학습, 재스케일하는 ASH-S와 적용 위치·제거 비율을 비교했다.
3. **방식:** 각 입력의 활성값 순위로 마스크를 만든다. 고정된 두 좌표를 모든 입력에 쓰는 방법이 아니다. 본문과 부록 A–L 확인.
4. **결과:** Table 2의 ImageNet 평균 FPR95는 Energy 58.41%, ASH-P 50.32%, ASH-4.0375초 상한 비반복 학습 22.73%, ASH-S 22.80%다. **제거만으로 얻은 이득과 남은 값 변형의 이득이 다르다.**
5. **해석:** 대량 제거 후 탐지 개선의 선례지만 에너지 점수와 주로 비음수 ReLU 표현에서 얻은 결과다. 우리 signed 표현에 그대로 옮길 수 없다. 또한 ASH-S의 양수 스케일이 마스크 후 벡터 전체에 동일하게 곱해지면 코사인에서는 상쇄된다. 이 마지막 설명은 코사인 수식에서 도출한 이번 검토의 해석이다. 부록 L도 작동 원인의 일부를 미해결 문제로 남긴다.

### 4.8 RankFeat — Song·Sebe·Wang, NeurIPS 2022

**문헌:** [RankFeat: Rank-1 Feature Removal for Out-of-distribution Detection](https://arxiv.org/abs/2209.08590).

1. **가설:** OOD 입력의 큰 첫 번째 특이성분이 과도한 확신을 유발하므로 이를 제거하면 탐지가 좋아진다.
2. **실험:** 최대 rank-1 성분 제거·유지, 여러 성분 제거, 적용 block, 점수 결합을 비교했다.
3. **방식:** 샘플별 채널×공간 특징 행렬을 SVD한 뒤 최대 특이성분을 빼고, 남은 네트워크와 에너지 점수를 사용한다. 본문과 부록 A–F 확인.
4. **결과:** Table 5에서 rank-1만 유지한 FPR95 58.49%보다 제거한 39.69%가 낫지만, 두세 성분 제거는 57.92/61.94%로 나빠진다. Table 2에서도 block에 따라 AUROC와 FPR95의 우열이 달라진다.
5. **해석:** 가장 큰 성분이 탐지에 항상 가장 좋은 성분은 아니며, 제거 효과가 단조롭지도 않다는 관련 사례다. 그러나 **최종 160차원 벡터의 두 좌표 선택과는 다르다.** 벡터 하나의 rank-1을 제거하면 벡터 전체가 사라진다. 정확한 재현에는 pooling 이전의 행렬이 필요하며, 현재 최종 벡터 캐시만으로 동일 실험을 했다고 할 수 없다.

### 4.9 Matryoshka Representation Learning — Kusupati 등, NeurIPS 2022

**문헌:** [Matryoshka Representation Learning](https://arxiv.org/abs/2205.13147). 검토본은 2024년 갱신 arXiv v4다.

1. **가설:** 하나의 긴 벡터 안에서 짧은 앞부분도 독립적으로 유용하게 학습할 수 있는가?
2. **실험:** 여러 차원의 부분 벡터를 공동 학습하고, 사후 SVD·무작위 특징·차원별 별도 모델과 비교했다.
3. **방식:** 예를 들어 8·16·32·…·2048차원 prefix 각각에 손실을 부여한다. 정규화가 필요한 경우 부분 벡터별로 처리한다. §3–5 및 부록 A–K 확인.
4. **결과:** ImageNet-1K Table 1에서 8차원 MRL 정확도는 66.63%, 무작위 특징의 linear probe는 4.56%다. 부록 K.1은 선형 head만 미세조정해서는 작은 차원에 정보를 충분히 모으지 못했다고 보고한다. 부록 J에는 차원이 증가해도 일부 클래스는 개선되지 않는 사례가 있다.
5. **해석:** 적은 차원으로 유용한 표현을 만드는 것은 확립된 연구 방향이다. 하지만 MRL은 **작은 벡터도 유용하도록 학습한 결과**다. 이번 EBM의 두 좌표 결과를 MRL과 같은 성공으로 주장할 수 없다. 차원 축소를 안정적으로 학습하려면 후속 공동 학습과 독립 검증이 필요하다는 방향을 준다.

### 4.10 Neural Collapse — Papyan·Han·Donoho, PNAS 2020

**문헌:** [Prevalence of Neural Collapse during the terminal phase of deep learning training](https://arxiv.org/abs/2008.08186).

1. **가설:** 학습 오분류가 거의 사라진 뒤에도 학습을 계속하면 마지막 층 표현과 분류기에 공통된 단순 구조가 나타나는가?
2. **실험:** 7개 이미지 데이터와 3개 모델 계열에서 학습 경과별 클래스 평균·공분산·분류기 정렬을 측정했다.
3. **방식:** 클래스 내 변동 감소, 클래스 평균의 simplex 구조, 평균과 분류기 정렬, 최근접 중심 판정과의 일치를 검증한다. §2–6, Figs. 1–8, 보충 증명 전체 확인.
4. **결과:** 학습 후반에 네 현상이 근사적으로 나타나는 경험적 결과를 제시하고, 특정 이상화 가정에서 중심 구조와 판정의 관계를 증명한다. 중심화된 원음 전체 비반복 학습개 클래스 평균의 simplex는 원음 전체 비반복 학습−1차원 구조다.
5. **해석:** 이진 문제에서 낮은 차원의 평균 구조가 나타날 가능성을 생각하게 한다. 그러나 EBM은 정상과 스푸프를 비대칭으로 학습하며, 우리는 DF 평가 분포를 보고 있다. **두 좌표 성능이나 두 군집 그림만으로 Neural Collapse를 확인한 것은 아니다.** 이진 클래스 간 공분산의 rank가 최대 1인 것은 일반적 대수 성질이므로, 클래스 내 분산 감소를 별도로 봐야 한다.

### 4.11 코사인 해석의 주의점 — Steck·Ekanadham·Kallus, WWW Companion 2024

**문헌:** [Is Cosine-Similarity of Embeddings Really About Similarity?](https://arxiv.org/abs/2403.05440).

1. **가설:** 학습 목표와 정규화가 만든 임베딩에서 코사인이 항상 의미 있는 유사도를 나타내는가?
2. **실험:** 닫힌 해를 구할 수 있는 정규화 선형 행렬분해와 시뮬레이션을 분석했다.
3. **방식:** 내적 예측을 유지하는 상호 역스케일링이 코사인은 바꿀 수 있음을 보이고, 정규화와 학습 목적의 영향을 분석한다. 수식 1–6, 시뮬레이션 및 §3의 해결책 확인.
4. **결과:** 내적으로 학습한 일부 모델에서는 코사인이 임의적이거나 정규화에 크게 좌우될 수 있다. 논문은 해결책 중 하나로 **코사인 자체를 학습 목표에 사용하는 것**을 제안한다.
5. **해석:** 표현과 이를 읽는 점수를 구분하는 데 유용하다. 그러나 EBM은 이미 코사인 기반으로 학습한다. 따라서 이 논문을 “EBM의 코사인이 의미 없다”거나 “코사인이 틀려 두 좌표가 좋아졌다”는 증거로 쓰면 부정확하다.

### 4.12 무음 편향 — Müller 등, ASVspoof Workshop 2021

### 4.13 Shortcut 검증 — Smeu 등, CVPR 2025

**문헌:** [Circumventing Shortcuts in Audio-visual Deepfake Detection Datasets with Unsupervised Learning](https://openaccess.thecvf.com/content/CVPR2025/papers/Smeu_Circumventing_Shortcuts_in_Audio-visual_Deepfake_Detection_Datasets_with_Unsupervised_Learning_CVPR_2025_paper.pdf).

1. **가설:** 합성 파이프라인의 짧은 앞 무음이 높은 탐지 성능의 shortcut이 될 수 있다.
2. **실험:** FakeAVCeleb·AV-Deepfake1M에서 무음 단독 탐지, 앞부분 제거, 감독·정상 전용 학습 모델을 비교했다.

5. **해석:** **다른 데이터셋에서도 같은 생성 편향이 있으면 교차 데이터셋 성능만으로 shortcut을 배제할 수 없다.** 이번에는 클래스뿐 아니라 출처·코덱·길이·padding을 맞춘 비교가 필요하다. 정상 중심 손실이라는 이름만으로 shortcut에 안전하다고 할 수 없으며 EBM의 표현 학습에도 스푸프 표본은 사용된다.

### 4.15 PCA와 OOD 점수 — Lakkapragada 등, 2024 공개본

**문헌:** [Comprehensive OOD Detection Improvements](https://arxiv.org/abs/2401.10176). 이번 검토는 arXiv 공개본 기준이다.

2. **실험:** 고정 모델의 표현에 PCA를 적용한 Mahalanobis·상대 Mahalanobis·KNN 및 DICE 변형을 평가했다.
3. **방식:** PCA로 좌표를 회전·결합한 뒤 다른 거리 점수를 계산한다. DICE-COL은 클래스별 연결 선택을 보완한다. 전체 방법·Tables 1–5 확인.
4. **결과:** 차원 축소 효과는 일관되지 않는다. Table 3의 ImageNet KNN AUROC는 near OOD 71.10→68.82%, far OOD 90.18→85.93%로 나빠지는 반면, CIFAR-100 Mahalanobis near OOD는 58.69→73.68%로 좋아진다.
5. **해석:** “차원을 줄이면 불필요한 정보가 없어져 항상 좋아진다”는 설명을 지지하지 않는다. 데이터·축소 방법·점수에 따라 다르다. PCA 산점도의 두 축과 원래 좌표 두 개도 동일한 대상이 아니다.

### 4.16 Frozen SSL와 간단한 분류기 — Pascu 등, Interspeech 2024

**문헌:** [Towards generalisable and calibrated audio deepfake detection with self-supervised representations](https://www.isca-archive.org/interspeech_2024/pascu24_interspeech.pdf).

1. **가설:** 고정된 큰 SSL 표현과 간단한 분류기 조합이 복잡한 탐지기보다 일반화와 calibration에 유리할 수 있는가?
2. **실험:** 여러 SSL 표현, 로지스틱 회귀·MLP·self-attention 분류기, 8개 데이터셋과 calibration을 비교했다.
3. **방식:** 고정 SSL의 평균 pooling 표현에서 새 분류기를 학습한다. 학습에는 2019 LA train과 dev를 함께 사용한다. Tables 1–4와 reliability 분석 확인.
4. **결과:** 8개 데이터 평균 EER는 RawNet2 30.9% 대비 해당 접근 8.8%다. Table 4의 별도 4개 데이터 평균 비교에서는 로지스틱 회귀 6.5%, MLP 8.2%, self-attention 11.3%다.
5. **해석:** 단순한 점수·분류기가 강한 표현을 잘 읽을 수 있다는 배경이다. 하지만 ‘학습 파라미터 2k 미만’은 **두 특징**이라는 뜻이 아니다. 새 분류기 학습과 calibration을 수행했으므로 기존 코사인을 유지한 이번 실험과 다르며, EER 개선과 calibration 개선도 구별해야 한다.

### 4.17 Poin-HierNet — Yang 등, Interspeech 2025

**문헌:** [Generalizable Audio Deepfake Detection via Hierarchical Structure Learning and Feature Whitening in Poincaré sphere](https://www.isca-archive.org/interspeech_2025/yang25l_interspeech.pdf).

1. **가설:** 공격·도메인의 계층 구조와 증강에 민감한 상관을 학습 중 제어하면 일반화가 좋아진다.
2. **실험:** Poincaré prototype 학습에 계층 학습과 feature whitening을 순차 추가했다.
3. **방식:** 160차원 표현을 쌍곡 공간으로 보내 여러 prototype과 비교하고, 원본·증강 표현 사이의 **D×D 상관 행렬**에 마스크를 둔 학습 정규화를 적용한다. §2–3, Table 2 확인.
4. **결과:** Table 2의 2021 DF EER는 PPL 1.95%, 계층 학습 추가 1.88%, whitening 추가 1.40%다. 이 변화는 재학습한 모델 사이의 비교다.
5. **해석:** 표현의 어떤 변동을 줄일 것인가라는 문제와 관련된다. 그러나 whitening의 마스크는 최종 출력의 일부 채널을 추론 시 제거한 것이 아니다. ‘채널 제거 선행연구’나 두 좌표 결과의 직접 근거로 소개하면 부정확하다.

### 4.18 학습 없는 코사인 탐지 — Pianese 등, IH&MMSec 2024

**문헌:** [Training-Free Deepfake Voice Recognition by Leveraging Large-Scale Pre-Trained Models](https://arxiv.org/abs/2405.02179).

1. **가설:** 특정 인물의 정상 참조 음성과 사전학습 표현만으로 가짜 목소리를 탐지할 수 있는가?
2. **실험:** 여러 frozen 모델의 참조 기반 탐지, 참조 수, 여러 데이터셋과 군집·점수 분포를 비교했다.
3. **방식:** **주장된 화자의 신원을 알고 정상 참조 음성을 가진 조건**에서, 테스트 표현과 참조 표현들의 최대 코사인을 사용한다. §2–3, Tables 1–2 및 Figs. 2–5 확인.
4. **결과:** BEATs 조합은 논문의 세 평가 조건에서 평균 EER 1.74%를 보고한다. Fig. 2의 t-SNE에는 클래스뿐 아니라 화자 구조도 보인다. ASVspoof 2021에서도 신원이 알려진 부분집합을 사용한다.
5. **해석:** 재학습 없는 코사인 탐지는 이미 존재한다. 그러나 일반 정상 센트로이드 하나를 사용하는 EBM과는 이용 가능한 정보가 다르다. 이 수치로 우리 2.92%의 우열을 판단할 수 없다. 군집이 화자·출처도 반영할 수 있음을 점검하는 배경이다.

### 4.19 저장 임베딩의 통계 변환 — Thani·Singh·Singh, 2026 공개본

**문헌:** [Unsupervised Domain Adaptation for Audio Deepfake Detection with Modular Statistical Transformations](https://arxiv.org/abs/2603.07935). 검토본은 arXiv v1, 9쪽이다.

1. **가설:** 고정 음성 임베딩에 해석 가능한 통계 변환을 적용하면 도메인이 바뀐 탐지가 좋아진다.
2. **실험:** 변환 단계를 순차 추가하며 ASVspoof↔FoR 전이를 비교했다.
3. **방식:** 저장 임베딩에 power transform, ANOVA 상위 512개 선택, 256차원 joint PCA, CORAL, 새 로지스틱 회귀를 적용한다. PCA와 CORAL에는 비라벨 목표 도메인 데이터를 사용한다. §3–6, Tables 1–3 및 논의 확인.
4. **결과:** Table 2의 ASVspoof→FoR EER는 baseline 48.1%, 전체 pipeline 37.4%다. 특징 선택 단계의 정확도는 54.5→58.0%다. **선택 단계 단독 효과와 전체 변환 효과는 다르다.**
5. **해석:** 캐시 기반 분석과 관련되지만, 재정규화 코사인이나 2차원 실험이 아니다. 목표 데이터를 쓰지 않는 일반화와도 다르다. 공식 ASVspoof 분할 대신 80/20 분할을 사용하며 화자 중첩 가능성을 인정한다. 데이터 총수와 클래스별 수의 합, ‘base’ 모델 명칭과 1024차원 기술 등 확인이 필요한 보고상 불명확성이 있어 핵심 수치 근거로 과도하게 의존하지 않는다.

## 5. 이번 결과를 설명할 수 있는 가설과 아직 구분되지 않은 것

후속 P1/P2/P3-A와F2/F3/F4의 완료 결과를 함께 고려해야 한다. dynamic gate의 전이EER 우월성은 미확인이고,선형 방향 잔차는 작은LL 이득과 EER 미개선이 함께 관찰됐다. source/codec/padding은class별전체u와연관됐다. 아래 문헌의 관련 사례를 우리 결과의 확정 원인이나 개선 보장으로 사용하지 않는다.

|---|---|---|---|
| 일부 좌표가 이 점수의 EER 부근에 불리한 변동을 더함 | DICE·ASH·RankFeat의 사후 제거 사례 | 선택 공간의 코사인에서 EER가 낮아진 점 추정치 | 마스크 후 재정규화 효과와 분자 기여 제거 효과를 분리 |

## 6. 군집 그림은 무엇을 보여주고 무엇을 증명하지 못하는가

이번 그림은 [두 좌표의 실제 값과 단위 방향](figures_clusters/01_selected_two_coordinates.png), [전체 표현의 PCA·t-SNE](figures_clusters/02_full160_pca_tsne.png), [표본·투영 조건](figures_clusters/captions.md)에 있다.

1. **두 좌표의 실제 산점도:** 원래 좌표값의 클래스 차이를 직접 보여준다. 두 좌표를 정규화한 원 위의 그림은 실제 사용한 코사인 방향과 대응한다. 두 좌표의 상관 약 0.973에는 클래스 평균 차이의 영향도 포함되므로 이것만으로 전체 표현의 차원을 판정하지 않는다.
2. **PCA:** 큰 분산이 놓인 선형 방향을 보여준다. 큰 분산은 판별에 중요한 정보와 같지 않다. Neural Collapse를 주장하려면 클래스 내 분산과 클래스 간 구조를 따로 측정해야 한다.
3. **t-SNE:** 이차원 투영에서 이웃 관계를 탐색하는 자료다. 그림에서 군집이 떨어져 보인다는 이유만으로 원래 코사인 판정의 오류가 없거나 잔여 차원이 불필요하다고 결론 내리지 않는다. 정량 판정은 원래 점수와 평가 지표로 해야 한다.
4. **선행연구와의 관계:** OC-Softmax는 t-SNE·PCA, ACS는 t-SNE, EBM 확장 논문도 DF t-SNE를 이미 제시했다. 우리 그림의 역할은 시각화 자체의 신규성보다 **선택한 실제 두 좌표와 원래 점수의 관계를 설명하는 것**이다.

## 8. EBM 저자에게 결과를 설명할 때 사용할 수 있는 범위

**사용할 수 있는 설명:**

> 학습이 완료된 한 EBM의 최종 160차원 임베딩에서, 학습 데이터의 단변량 Fisher 점수로 정한 일부 좌표만 사용하고 정상 센트로이드에도 같은 좌표 선택을 적용했습니다. 선택 공간에서 두 벡터를 다시 정규화한 후 기존과 같은 코사인 점수를 계산했습니다. DF 고정 표본에서는 Fisher 하위 두 좌표의 EER가 전체 표현보다 낮은 점 추정치를 보였지만, AUROC와 일부 운용점에서는 전체 표현이 더 좋았습니다. 이 결과는 해당 표현에서 좌표 선택과 코사인 정규화가 오류 관계를 바꿀 수 있음을 보여주는 탐색 결과로 보고 있습니다.

**현재 근거를 넘는 설명:**

- ‘중요한 상위 두 채널에 모든 정보가 집중됐다.’ 실제 두 좌표는 Fisher **하위**이며, 모든 정보의 보존을 검증하지 않았다.
- ‘나머지 158개는 잡음이고 판정에 방해만 한다.’ AUROC와 일부 운용점에서는 전체 표현이 더 좋다.
- ‘EBM은 사실상 2차원 모델이다.’ 전체 encoder와 160차원 LayerNorm을 계산한 후 점수 좌표만 줄였다.
- ‘Fisher 하위 선택이 더 잘 일반화한다.’ 하나의 DF 표본을 반복 탐색한 결과이며 별도 검증이 필요하다.
- ‘Neural Collapse를 발견했다.’ 관련 정량 조건과 학습 경과를 확인하지 않았다.
- ‘소수 특징 탐지 또는 군집 시각화 자체가 최초다.’ 직접 관련된 선행연구가 있다.

## 9. 검색·열람 범위와 확인 기록

**검색 기준일:** 2026-11-05. 주로 arXiv 원문, ISCA Archive, CVF Open Access, 학회·출판사 원문, 저자 공개 PDF와 출판기관 기록을 확인했다. 블로그의 요약과 검색 결과의 초록만으로 본문 결과를 확정하지 않았다.
