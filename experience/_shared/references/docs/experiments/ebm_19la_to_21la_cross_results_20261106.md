# 19LA → 21LA 정상·스푸프 교차 평가

2026-11-06 KST. 이번 비교의 외부 평가 대상은 DF가 아닌 **21LA**다. 이전 21LA→DF 기준 비교와 구분한다. 동일한 고정 EBM의 로컬 점수를 조합했고 새 GPU·음성 추론·학습·SSH는 없었다. 추가 계산은 1.33초였다.

**21LA의 EER 증가도 정상 점수 집합 교체에 의해 주도됐다.** 정상 교체는 스푸프 집합을 19LA 또는 21LA로 고정한 양쪽에서 모두 EER를 높였다. 스푸프 교체는 점추정상 EER를 낮췄지만, 19LA 정상을 고정한 작은 개선은 네 비교 보정 구간에서 0과 접한다. 이 결과는 점수 분포 진단이며 학습 원인의 인과적 증명이 아니다.

전체 EER 차이는 +0.618362pp, 95% 군집 구간 [0.379412, 0.909052]pp다. 네 edge 효과를 합산하지 않는다. EER 비선형성에 따라 상대 클래스와 교체 순서에 의존한다.

검증 V 스푸프 FAR≤1% 규칙의 고정 임계값 약 −0.909973에서는 정상 오거부가 19LA 0.027192%→21LA 0.411717%, 스푸프 통과가 9.520679%→7.057588%였다. 균형 오류는 4.773936%→3.734653%로 낮아진다. 따라서 결론은 **EER 악화에 대한 것**이며 모든 운용점의 총 오류 증가를 뜻하지 않는다.

공유 ASV 화자 67개의 bootstrap 가중치를 두 평가셋에 동일하게 적용했다. 앞선 검수의 seed 2026110522, 2,000회 출처별 군집 draw를 재사용했고 교차 EBM-NoRepeat와 EBM-FullContext 점수의 bootstrap을 이번에 추가 계산했다. VCC 열은 이 두 평가셋에서 표본이 없으므로 가중치가 계산에 영향을 주지 않는다. 보정 구간은 이번 네 edge 비교에 대한 Bonferroni 구간이며 프로젝트 전체 동시 보장이나 사전 등록 확인 실험이 아니다.

원본 score parquet의 SHA256·동일 체크포인트, 독립 DET EER와 rank AUC, 가중 ROC의 균등 가중치 점추정, 이전 출처 교차행렬, 기존 A/D bootstrap draw의 정확한 재현을 확인했다. 결과는 `summary.json status=pass`, `complete=0`이다.

19LA와 21LA는 기반 자료를 공유하며 21LA는 전송·채널·codec 변화가 포함된다. 이 실험은 미지 공격 기법의 순수 효과를 측정하지 않는다. 공유 원발화·재인코딩 family 대응의 미해결과 단일 체크포인트의 학습 불확실성은 군집 구간에 포함되지 않는다. 길이·codec을 맞춘 별도의 21LA 민감도 검사는 이번에 수행하지 않았다.
