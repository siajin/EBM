## 실험 1. 전체 체크포인트 최소 EER와 같은 epoch 비교

기존240은 보존된15·20·25·30·35·40·45·50epoch 8개다. B·C와 이번 모델은5·10·…·50epoch 10개씩이다. 총38개 체크포인트를 두 입력 조건·세 집합에서 평가한다.

- 전체 보존 체크포인트 중 최소 EER, 해당 epoch, 후보 수를 보고한다.
- 공통15~50epoch 8개에서의 최소 EER도 함께 보고한다.

해석: 조건별 최적 체크포인트가 바뀌어 생기는 차이와, 같은 체크포인트에서 입력 반복만 바꿔 생기는 차이를 구별한다. 집합별 최소값은 target을 본 사후 최솟값이다. 한 번 선택한 단일 모델의 비편향 배포 성능으로 주장하지 않는다.

## 실험 2. 원음 길이별 분리력·오류 전이
