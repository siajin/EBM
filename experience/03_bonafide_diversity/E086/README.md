# E086. 이전 80epoch 모델의 정상 기준 각도와 160차원 분포

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

정상중심 학습은 대부분정상을 좁은각도로 모으면서 일부도메인 꼬리를 남길 수 있다.

## 그렇게 설계한 이유

초기 모델의 정상·위조 특징이 학습 정상 기준 벡터 주위에 어떻게 놓이는지 측정한다.

대조와 통제의 근거: 학습된 기준 벡터를 정상 평균으로 바꾸지 않는다. 클래스 균형 표본은 DF 전체의 실제 클래스 비중과 다르다.

## 모델·데이터·표본

배치 80·80epoch의 고정 모델(체크포인트 SHA256 30043199664bc84da780654e01fd430235f647b894e7832a52f777c7fee5939a). 별도 명시가 없으면 DF eval에서 seed 1로 정상·위조 각 1,000개를 클래스 안에서 중복 없이 무작위 추출한 같은 2,000개다. 추론 배치 4, worker 2, 원래 앞 64,600샘플·부족하면 순환 반복, 증강 없음이다.

## 실험 내용과 상세 절차

1. 마지막 LayerNorm 출력 160차원을 길이 1로 정규화하고 학습된 정상 기준 벡터와 코사인·각도를 계산한다.
2. 클래스별 평균·표준편차·5/50/95백분위와 원래 160차원에서의 각도를 기록한다. PCA 그림은 별도 투영으로 표시한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

정상 코사인 중앙값 0.989413·각도 중앙값 8.34472°, 위조 코사인 중앙값 −0.977272·각도 167.76099°였다. 정상의 낮은 점수 꼬리가 보였다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

정상중앙값이좋아도 낮은점수꼬리를 놓치면 안 된다. 단일탐색표본을 전체benchmark로 부르지 않는다.
