# 다른 출처·라벨의 저에너지 프레임을 이식한 실험

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

길이·에너지를맞춘 다른출처·라벨의 저에너지질감이 점수에 이식될 수 있다.

## 그렇게 설계한 이유

길이·에너지를 맞춘 저에너지 질감에서 정상/위조·출처 효과가 재현되는지 본다.

대조와 통제의 근거: 제공 라벨 이식 효과와 출처 효과는 별도다. 0 교체와 달리 수신 구간의 평균·분산·바깥 샘플을 보존한다.

## 모델·데이터·표본

고정 80epoch 모델, 새 DF 수신자 2,000개, seed 9241. 코덱·화자 분리 제공자 묶음과 실제 프레임 배정은 보존 원명세를 따른다.

## 실험 내용과 상세 절차

1. ASVspoof·VCC2018·VCC2020별로 화자가 겹치지 않는 동일 구현의 반복 입력·비반복 입력 대조 제공자 묶음을 만든다. 같은 출처·화자·코덱의 정상/위조 제공자를 맞춘다.
2. 원래 앞 저에너지 20ms 프레임에서 처음·끝 16샘플은 두고 내부 288샘플만 교체한다. 수신 프레임의 내부 평균·분산을 복원하며 다른 위치는 그대로 둔다.
3. 수신 원음마다 최대 8개의 고유 제공 프레임과 같은 재사용 순서를 모든 12개 제공 조건에 공통 사용한다. 기준·무변형·자기 재사용·자기 섞기·가우시안 잡음 대조까지 총 17조건이다.
4. 주비교는 같은 출처에서 정상 제공자−위조 제공자, 두 제공자 묶음 평균이다. 양쪽·두 묶음 모두 진폭 복원 10배 이하인 수신자만 주집단으로 삼고 전체 결과를 보조로 둔다.
5. 제공자 묶음별 결과, 수신자 코덱 일치 부분, 접합이 작은 부분, 프레임 비반복 부분, 제공 화자 하나씩 제외한 범위도 보고한다.

## 측정과 검증

입력 프레임 에너지·평균·바깥 샘플 보존과 제공자 매칭 검증. 수신 화자 군집 구간은 실현된 제공자 묶음에 조건부이며 제공 화자 수가 적은 제한을 포함한다.

## 결과

수신자 2,000개 중 원래 적합 정상 931개·위조 887개였다. ASV 제공자의 정상−위조 주비교는 정상 수신자 831개에서 +0.001940, 위조 수신자 818개에서 +0.000396이었다. 모든 출처에 일관된 큰 정상 방향 효과를 확정하지 못했다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

일관되고큰 제공라벨효과는확립하지 못했다. 제공자수와재사용·진폭복원 제한을 함께보고해야 한다.
