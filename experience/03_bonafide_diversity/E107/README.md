# E107. 고정 BPL 학습 모델의 실제 증강 쌍·저에너지 이식 반응 검토

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

BPL로높은쌍유사도를학습했어도 저에너지개입 민감도가 남을 수 있다.

## 그렇게 설계한 이유

긴·짧은 정상 쌍이 가까워도 저에너지 변형에 둔감하다는 보장이 있는지 본다.

대조와 통제의 근거: 평가 모드에서 한 번 만든 실제 증강 쌍은 과거 전체 epoch의 학습 손실이 아니다. 추론 BPL 계산을 끄는 것은 BPL 없이 학습하는 대조가 아니다.

## 모델·데이터·표본

고정 80epoch 모델. 800개 입력 조건 진단과 별도 적합 DF 수신자 1,014개. 여러 후속 표본은 서로 겹치며 합산하지 않는다.

## 실험 내용과 상세 절차

1. 개발·DF에서 정상·위조 각 200개씩 총 800개를 고정한다. 원래 긴 입력, 무증강 무작위 짧은 입력, 긴/짧은 저에너지 순서 섞기, 실제 TrainSet 방식 증강 긴/짧은 입력의 여섯 조건을 만든다.
2. 동일 발화 유사도, 모든 정상 교차 쌍과 4개씩 묶은 진단 BPL, 최소 가능한 BPL보다 큰 손실, 정상 기준 점수 차이를 계산한다. 위조 BPL은 진단 계산일 뿐 원래 학습 목적에 포함하지 않는다.
3. DF의 엄격 출처·화자·코덱 일치 수신자 1,014개에 기준·무변형·두 번의 정상/위조 제공자·내부 순서 섞기의 일곱 조건을 적용한다. 프레임 경계 16샘플·평균·분산·구간 밖 샘플을 보존한다.
4. 추론에서 BPL 계산을 끄고 켠 점수가 같은지, 실제 증강의 앞 저에너지 보존과 고유 원음 선택, 두 제공자 추출의 변동을 확인한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

개발 정상 실제 증강 쌍 평균 코사인 0.965200, 무증강 0.998206이었다. 높은 쌍 유사도와 0.01 이상 정상 점수 변화가 함께 발생하는 반례가 있었고, 제공 라벨의 일관된 정상 방향 이동은 확인되지 않았다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

반례를확인했다. 추론에서BPL계산을끄는것은 BPL없이재학습한 ablation이 아니다.
