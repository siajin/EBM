# 잔여 방향·좌표·거리·기하와 변형 반응

## 연구 질문과 설계 배경

단일 정상 중심과의 각도 밖에 판별 신호가 남고, 이를 읽거나 조절해 전이 성능을 높일 수 있는가?

내부CV에서 방향 신호는 남았지만 고정 후처리의 독립 전이 이득은 확립하지 못했다. 좌표·회전·매칭 지지·관찰 밀도와 수학적 자유도를 구분한다.
