# 저에너지 시간 위치와 나머지 XLS-R 특징을 교체·제외한 내부 개입

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

저에너지구간의영향은 XLS-R문맥을통해 다른시간위치에도 퍼질 수 있다.

## 그렇게 설계한 이유

저에너지 파형의 영향이 그 시간 위치의 특징에만 갇혀 있는지 확인한다.

대조와 통제의 근거: 중간 특징을 섞은 가상 조합은 자연 음성이 아니다. 두 부분의 점수 기여가 합쳐 100%라는 가정을 하지 않는다.

## 모델·데이터·표본

[고정 BPL 학습 모델의 실제 증강 쌍·저에너지 이식 반응 검토](../../03_bonafide_diversity/E107/README.md)의 고정 모델과 96개 무작위 사례. 같은 입력의 파형 개입·내부 특징 개입을 구별한다.

## 실험 내용과 상세 절차

1. [고정 BPL 학습 모델의 실제 증강 쌍·저에너지 이식 반응 검토](../../03_bonafide_diversity/E107/README.md)에서 효과 크기를 보지 않고 개발/DF×클래스마다 24개씩 총 96개를 뽑는다.
2. 원본·저에너지 변형의 25개 XLS-R 층을 계산하고, 전체 합성곱 수용 구간이 저에너지 선택 구간 안에 든 프레임만 저에너지 위치로 표시한다.
3. 원본, 변형, 저에너지 위치만 교체, 다른 위치만 교체, 원본의 저에너지 위치를 모든 후속 시간 요약에서 제외, 변형의 같은 위치 제외의 여섯 조건을 비교한다.
4. pooling 잡음은 0으로 하고 가중치는 고정한다. 원래 특징 조합의 점수 재현을 검사한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

저장 완료·검수는 통과했으며 저에너지 위치를 XLS-R 뒤에서 제외해도 무작위 96개에서 모든 반응이 사라지지는 않았다. 문맥 특징이 다른 시간에도 영향을 담을 가능성이 남았다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

해당위치를제외해도 모든반응이 사라지지 않았다. 내부특징교체를 자연음성 인과기여로 단순합산하지 않는다.
