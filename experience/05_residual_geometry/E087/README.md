# E087. 특징 추출 단계별 분리와 같은 원음의 긴·짧은 특징 비교

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

클래스분리는 frontend보다 학습backend에서 커질 수 있으며 긴·짧은view의 유사도와 별개일 수 있다.

## 그렇게 설계한 이유

어느 처리 단계에서 두 클래스가 갈라지고 길이 변화에 어떤 일관성이 있는지 기술한다.

대조와 통제의 근거: 단계마다 차원과 요약 방식이 다르다. 단계별 독립 PCA의 화면 축을 같은 축으로 간주하지 않는다.

## 모델·데이터·표본

배치 80·80epoch의 고정 모델(체크포인트 SHA256 30043199664bc84da780654e01fd430235f647b894e7832a52f777c7fee5939a). 별도 명시가 없으면 DF eval에서 seed 1로 정상·위조 각 1,000개를 클래스 안에서 중복 없이 무작위 추출한 같은 2,000개다. 추론 배치 4, worker 2, 원래 앞 64,600샘플·부족하면 순환 반복, 증강 없음이다.

## 실험 내용과 상세 절차

1. XLS-R 시간 요약 1,024차원, 층 결합 뒤 128차원, 최종 시간 요약 256차원, 선형 출력 160차원, LayerNorm 뒤 160차원을 각각 저장한다.
2. 단계별 길이 1 정규화 특징에서 클래스 내부·클래스 사이 평균 코사인과 독립 PCA의 설명 분산을 계산한다.
3. 같은 원음의 64,600샘플 긴 입력과 원음 전체에서 seed로 고정한 48,440샘플 짧은 입력을 비교한다. 증강은 끈다.
4. 정상 긴·짧은 모든 교차 쌍의 유사도도 계산하되, 실제 학습의 미니배치 손실이라고 부르지 않는다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

클래스 사이 평균 코사인은 XLS-R 요약 0.978812에서 선형 출력 −0.796033으로 바뀌었다. 같은 원음 긴·짧은 평균 유사도는 정상 0.960920·위조 0.964259였다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

단계별차원과투영이 다르므로 화면축을 비교하지 않는다. 높은쌍유사도가 모든변형강건성을 보장하지 않는다.
