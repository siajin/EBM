# 스푸프 중심 EBM의 역할 전환

## 연구 질문과 설계 배경

정상 대신 알려진 위조를 한 중심과 전체쌍 BPL로 모으고 정상을 밀어내면 일반화에 도움이 되는가?

역할 대응 구현과 CPU 회귀·분산 검증만 완료됐다. 실제 GPU 학습·미지 공격 EER은 확보되지 않았다. 평가 부호와 smoke 범위 오류를 재현·수정했다.

## 실험별 상세 기록

각 항목에 가설, 설계 이유, 데이터·통제, 절차, 실제 결과, 실패·한계, 배운 점, 코드와 근거를 담았다. 검증·캐시생성·설계만인 항목을 독립 성능 실험으로 세지 않는다.
