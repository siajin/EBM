# E092. 저에너지 가장자리 제거 후 반복·0 채움 위치를 달리한 대조

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

저에너지를제거한뒤 채움방식을 바꾸면 제거내용과위치의 영향을 구분할 수 있다.

## 그렇게 설계한 이유

가장자리 제거 효과가 남은 본문·반복·0 채움 위치 중 무엇과 함께 달라지는지 본다.

대조와 통제의 근거: 잘라 낸 내용과 0의 위치를 다르게 통제한 조건이다. 자동 기준이 실제 비발화 구간의 정답은 아니다.

## 모델·데이터·표본

배치 80·80epoch의 고정 모델(체크포인트 SHA256 30043199664bc84da780654e01fd430235f647b894e7832a52f777c7fee5939a). 별도 명시가 없으면 DF eval에서 seed 1로 정상·위조 각 1,000개를 클래스 안에서 중복 없이 무작위 추출한 같은 2,000개다. 추론 배치 4, worker 2, 원래 앞 64,600샘플·부족하면 순환 반복, 증강 없음이다.

## 실험 내용과 상세 절차

1. [E091](../E091/README.md)의 상대 −20dB 규칙으로 앞뒤 저에너지 가장자리를 제거한다.
2. 원래 반복 기준, 제거 후 반복, 제거 후 오른쪽 0 채움, 제거 후 양쪽 중심 0 채움, 원래 위치의 가장자리만 0 교체를 비교한다.
3. 원래 표본 EER 운영점의 코사인 −0.561922848을 고정한 오류와 각 조건 자체 EER을 따로 계산한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

순서대로 표본 EER은 2.0/3.3/3.8/3.4/2.3%, 정상 코사인 0.9 미만 개수는 163/908/201/257/354였다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

같은제거라도 채움위치에따라 결과가달랐다. 자동저에너지선택을 정답무음으로 부르지 않는다.
