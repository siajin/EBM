# 반복 입력과 학습·추론의 상호작용

## 연구 질문과 설계 배경

순환 반복이 모델에 내용 외의 문맥·반복량 단서를 만들며 학습과 추론의 일치가 성능에 영향을 주는가?

배치 240 고정 길이 반복 입력 학습은 반복 입력, 4.0375초 상한 비반복 학습은 비반복 입력에서 유리했다. 반복의 보편적 해로움은 입증되지 않았다. 파형반복과 후기 특징복제는 다른 결과를 냈다.
