# E091. 파형 크기·반복·0 채움·반사·가장자리 절단의 초기 교차 개입

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

진폭·반복·가장자리정책이 정상꼬리를 크게 움직일 수 있다.

## 그렇게 설계한 이유

정상 꼬리가 단순 크기나 길이 처리에 민감한지 직접 측정한다.

대조와 통제의 근거: 내용·위치·길이가 함께 달라지는 조건과 진폭만 달라지는 조건을 구별한다.

## 모델·데이터·표본

배치 80·80epoch의 고정 모델(체크포인트 SHA256 30043199664bc84da780654e01fd430235f647b894e7832a52f777c7fee5939a). 별도 명시가 없으면 DF eval에서 seed 1로 정상·위조 각 1,000개를 클래스 안에서 중복 없이 무작위 추출한 같은 2,000개다. 추론 배치 4, worker 2, 원래 앞 64,600샘플·부족하면 순환 반복, 증강 없음이다.

## 실험 내용과 상세 절차

1. 원래 반복 입력, 전체 진폭 0.25배, 부족분 오른쪽 0 채움, 반사 채움, 가장자리 저에너지 제거 후 반복, 반복 없는 원음 입력을 같은 발화에 적용한다.
2. 앞뒤 저에너지 제거는 해당 파일 최대 20ms 프레임 RMS의 10%보다 작은 가장자리 구간을 제거하는 상대 −20dB 규칙이다.
3. 클래스별 점수 변화, 원래 꼬리 회복·새 꼬리 발생, 출처·반복 필요 여부별 결과와 표본 EER을 계산한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

반복 없는 입력은 꼬리 163→52개로 줄였지만 같은 표본 EER은 2.0→5.9%로 높아졌다. 가장자리 제거 후 반복은 정상 꼬리를 908개로 늘렸다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

꼬리는줄었어도 비반복EER은 악화했다. 정상회복만으로 전처리개선을 판정하면 안 된다.
