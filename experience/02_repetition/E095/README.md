# 이전 모델에서 특징 복제와 통계 요약의 길이 배율을 분리

**실행 상태:** 기존 실제 결과 확인·문서화 완료

이 문서의 상태는 2026-11-12 출판 검토 기준이다. 기존 문서·state의 시점별 상태와 충돌하면 실제 완료표식과 본문 최신 보완을 우선한다.

## 가설

반복없는추론의손상은 pooling표준편차의 프레임수배율로 설명될 수 있다.

## 그렇게 설계한 이유

반복의 효과가 최종 표준편차 계산의 프레임 수 의존성만으로 생기는지 검사한다.

대조와 통제의 근거: 표준적인 가중 표준편차로 구조를 교체한 것이 아니다. 파형 반복으로 XLS-R 문맥이 바뀌는 효과는 우회한다.

## 모델·데이터·표본

배치 80·80epoch의 고정 모델(체크포인트 SHA256 30043199664bc84da780654e01fd430235f647b894e7832a52f777c7fee5939a). 별도 명시가 없으면 DF eval에서 seed 1로 정상·위조 각 1,000개를 클래스 안에서 중복 없이 무작위 추출한 같은 2,000개다. 추론 배치 4, worker 2, 원래 앞 64,600샘플·부족하면 순환 반복, 증강 없음이다.

## 실험 내용과 상세 절차

1. pooling 잡음을 0으로 끈다. 원래 201프레임 특징을 시간축으로 두 번 복제해 402프레임으로 만든다.
2. 최종 시간 요약 직전 특징 복제와 25개 XLS-R 층 전체 특징 복제를 구별한다. 파형은 반복하지 않는다.
3. 원래 요약식 std(alpha*h)의 복제 배율 sqrt(2(T−1)/(2T−1))/2를 최종 표준편차 부분에 직접 적용한 결과와 비교한다.
4. 반복 없는 원음 특징에 최종 요약만 또는 모든 요약의 명시적 길이 배율을 기준 201프레임에 맞추는 보조 조건을 계산한다.

## 측정과 검증

발화별 대응 점수·원래 160차원 코사인·클래스별 분모와 저장 검산을 확인한다.

## 결과

복제의 표준편차 배율은 0.499376이고 직접 배율 조정과의 점수 최대 차이는 2.38e-7이었다. 반복 없는 조건의 EER 5.9%는 길이 배율 조정 후에도 같았다.

## 해석·실패한 부분·한계

하나의 고정 학습 모델과 탐색 표본의 결과다. 전체 공식 평가 EER, 여러 학습 seed의 효과, 손실을 제거한 재학습의 효과로 해석하지 않는다. 반복 관찰한 표본과 서로 겹치는 후속 분석은 독립 실험 표본으로 합산하지 않는다.

## 배운 점

대수적복제효과는 맞췄으나 길이보정만으로 비반복EER을 해결하지 못했다. 문맥효과가 별도로남는다.
