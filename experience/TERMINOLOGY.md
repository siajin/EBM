# 모델 이름과 평가 용어

## 모델과 학습 방식

|文書で使う名前|意味|
|---|---|
|EBM-NoRepeat|긴 입력은 원음 앞 최대 64,600샘플, 짧은 입력은 최대 48,440샘플의 연속 무작위 구간. 더 짧은 원음은 반복하지 않으며 배치 정렬의 0 채움은 마스크로 제외|
|EBM-FullContext|직전 학습의 긴 입력 상한만 해제해 원음 전체 사용. 짧은 입력 상한과 비반복 처리는 유지. 평가는 계속 앞 64,600샘플로 제한|
|EBM-Repeat|긴 입력 64,600샘플·짧은 입력 48,440샘플. 원음이 부족하면 순환 반복. GPU별 정상 12·위조 108을 사용|
|길이·음성활동·원음 전수 노출을 맞춘 학습|클래스·화자·공격별 길이 정책, 음성활동 조정, 매 epoch 원음 전수 방문과 독립 정상 묶음 정렬을 결합한 복합 학습|
|짧은 정상 음성의 3.0275초·2초 정렬 학습|원음이 2초 이하인 정상 음성에만 3.0275초·2초 입력의 정상쌍 손실을 결합. 해당 행의 기존 긴×짧은 손실 가중치도 조정|
|완만한 속도·절단 변형|원음의 최소 80% 구간을 남기고 속도 0.8~1.2배로 변형한 학습 자료. 이후 고정 길이 입력을 만들 때의 추가 절단·반복과 구분|

길이는 16kHz 기준이다. 원래 고정 입력의 정확한 길이는 4초·3초가 아니라 **4.0375초·3.0275초**다. 원음 전체를 쓴다는 표현은 긴 **학습** 입력에 대한 것이며, 기본 평가 입력의 상한을 없앴다는 뜻은 아니다.

## 평가·학습 용어

|용어|뜻|
|---|---|
|EER|동일 오류율. 정상 거부율과 위조 통과율이 같아지는 ROC 지점의 보간 오류율. 단위는 %이며 낮을수록 좋음|
|2019 LA·2021 LA·2021 DeepFake|각각 ASVspoof 2019 Logical Access·ASVspoof 2021 Logical Access·ASVspoof 2021 DeepFake 평가 집합. 원자료의 짧은 집합 키는 기계 판독을 위해 보존|
|epoch|학습 데이터의 한 순회 단위. 서로 다른 sampler에서는 실제 방문·갱신 수를 별도로 확인해야 함|
|배치 240|두 GPU를 합한 논리 입력 수. 물리 배치 8의 분할 계산과 다른 개념|
|정상쌍 학습(BPL)|배치의 정상 긴 입력과 정상 짧은 입력 사이의 전체 교차쌍을 정렬하는 손실|
|OC 중심|학습되는 정상 또는 위조 기준 벡터. 정상 특징의 산술평균과 다름|
|VAD|음성활동 자동 추정. 여기서는 구간의 활동량 정책을 만드는 데 사용하며 정답 무음 표지가 아님|
|native·wrap|원자료에 남은 입력 처리 키. 각각 원음 길이 유지·부족한 입력의 순환 반복을 뜻함|
|고정 저장점 결과|미리 지정한 epoch 모델의 평가. 각 집합의 사후 최저값과 구분|
|관측 최소|평가한 저장점들 가운데 사후에 얻은 최소 EER. 집합별 최소를 모아 단일 모델의 성능으로 제시하지 않음|

모델 브랜치는 `models/repeat`, `models/no-repeat`, `models/full-context`로 통일했다. 실제 학습 파일·결과 열의 식별자는 재현을 위해 유지한다. 문서의 제목·비교 표·본문·링크 이름은 학습 방식이 드러나는 설명형 이름으로 표시한다. 수식의 변수와 분류기 규제 계수는 모델의 별칭과 구분한다.
