# 확정 결과와 비교 범위

EER의 단위는 %이며 낮을수록 좋다. 공식 평가 전체는 2019 LA 71,237개, 2021 LA 148,176개, 2021 DeepFake 533,928개다. 모델 이름과 평가 용어는 [용어 안내](TERMINOLOGY.md)에 정리했다.

<a id="같은-비반복-기본-입력의-고정-checkpoint"></a>

## 같은 비반복 기본 입력의 고정 저장점

모든 행은 앞 64,600샘플 상한·비반복·유효 길이 마스크·배치 8·각 모델의 학습 OC 중심 코사인을 사용한다. 원래 통계 pooling 잡음 1e-5를 유지한다. 고정 길이 반복 학습과 EBM-NoRepeat의 공통 입력 비교, 두 비반복 학습의 전체 저장점 공통 실행, 나머지 별도 실행을 구분한다. 학습 epoch와 실제 평가 난수는 행마다 다르다.

|EBM-Repeat|50|1.128484|6.688715|8.877530|[공통 평가](02_repetition/E009/README.md)|

<a id="지정25epoch-비교"></a>

## 지정 25epoch 비교

기본 평가 정책은 같지만 조건부 길이 정렬 학습과 두 비반복 학습은 별도 평가 실행의 난수다. 조건부 길이 정렬은 기존 긴×짧은 손실의 대상 행 가중치도 줄였으므로 추가 3.0275초·2초 항만의 독립 효과는 분리하지 못했다.

|학습 방식|2019 LA|2021 LA|2021 DeepFake|
|---|---:|---:|---:|
|EBM-NoRepeat·25epoch|0.788579|5.009748|2.512431|
|EBM-FullContext·25epoch|0.652617|5.248950|2.730513|
|짧은 정상 음성의 3.0275초·2초 정렬 학습·25epoch|1.210061|11.308488|5.427399|

이 지정 저장점 비교에서는 짧은 정상 음성의 길이 정렬 학습이 세 집합 모두 나빴다.

<a id="bc-전체10개-저장점의-관측-최소"></a>

## 두 비반복 학습의 전체 10개 저장점 관측 최소

각 집합에서 5~50epoch의 10개 저장점을 본 사후 최소다. 집합별 최적 epoch가 다르며 독립 검증에서 고른 단일 모델의 성능이 아니다.

|학습 방식|2019 LA 최소(epoch)|2021 LA 최소(epoch)|2021 DeepFake 최소(epoch)|
|---|---|---|---|
|EBM-NoRepeat|0.462271 (45)|3.759449 (45)|2.084875 (5)|
|EBM-FullContext|0.488400 (40)|4.622076 (30)|2.152549 (5)|

## 과거 반복 평가 참고값

과거 EBM-Repeat의 기록된 최소는 2019 LA 0.217539%(25epoch), 2021 LA 1.052789%(50epoch), DeepFake 2.396259%(15epoch)다. 이는 15~50epoch의 8개 저장점·과거 반복 평가다. 두 비반복 학습의 10개 저장점 비반복 평가 최소와 입력·후보 수가 다르다. 과거 실제 코덱 적용 여부도 미확정이다. [초기 배치 크기·정상쌍 구성 기록](README.md)

두 고정 50epoch 모델의 2021 LA 반복 진단에서는, 고정 길이 반복 학습의 EER이 비반복 6.688715→반복 1.052789%, EBM-NoRepeat 모델은 비반복 4.792117→반복 7.736953%였다. 이 진단의 pooling 잡음은 0이다. 반복의 보편적 해로움보다 학습 모델과 입력 정책의 상호작용을 지지한다. [전체 원음의 반복·비반복 교차 진단](02_repetition/E014/README.md)

<a id="성능으로-결론-낼-수-없는-항목"></a>

## 완료 성능으로 결론 낼 수 없는 항목

완만한 변형을 적용한 원본 방식 학습은 진입 오류·평가 import 오류로 완료 EER이 없다. 배치 320은 첫 배치 메모리 부족으로 종료했다. 추가 38개 저장점 공통 평가는 실행 전에 취소했다. 스푸프 중심 학습은 로컬 구현·86개 검사까지이며 실제 GPU 학습 EER은 없다. DeepFake 내부 교차검증의 방향 판독 이득은 학습 자료에서 미지 도메인으로 전이한 성능과 구분한다.

## 근거 우선순위

실제 평가 지표·완료 확인·독립 검산 → 고정 코드·설정 → 검토된 방법 기록 → 당시 문서·계획 순으로 읽는다. 합성 12행 검수 표, 학습 전 smoke 검사, 과거 상태 파일의 진행 중 문구를 실측 최종 성능으로 사용하지 않는다.
