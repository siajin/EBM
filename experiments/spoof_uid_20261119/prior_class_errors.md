## 학습 전 완료 모델 클래스 오류 비교

두 이전 모델 모두 스푸프 BPL은 all-cross다. 정상 BPL만 전체 교차(v3)와 같은 UID(v4)가 다르다. 각 데이터셋 전체 공식 UID·라벨을 대조했다. 40/50epoch × 두 모델 × 세 데이터셋의12개 EER를 독립 재계산했으며 최대 오차는 약7.4e−15%p다. 추론·재학습 없이 완료 점수만 읽었다.

정상 거부율=정상 중 스푸프로 거부한 비율, 스푸프 통과율=스푸프 중 정상으로 통과한 비율이다. score_bona ≥ threshold면 정상으로 판정한다. 모델별19LA eval에서 실제 가능한 EER 최근접 임계값을 고르고21LA/DF에도 고정한다. 서로 다른 점수척도에 같은 숫자 임계값을 강제하지 않는다. 설명용 eval 기반 임계값으로 운영 검증/독립 보정 성능은 아니다.

### 해석

정상 same-UID는19LA에서는 소폭 개선되고21LA의 정상 거부도 줄지만, 타 도메인 정상 거부율이 여전히 높다. 40epoch21LA에서는 거부율 차이가−0.0405%p에 그치고 스푸프 통과가 증가한다. 같은 UID로 바꾸는 것만으로21LA 열화를 해결했다고 볼 수 없다.

DF는19LA EER 임계값에서 UID의 정상 거부가 늘고 스푸프 통과가 줄었다. 하지만50epoch의 source FAR0.5% 고정 비교에서는 정상 거부도20.6134→20.3174%로 개선된다. 따라서 DF 정상 분포가 일관되게 악화됐다고 단정할 수 없으며 판정 기준과 epoch에 의존한다. 두 방식 모두 타 도메인 오류율의 클래스 편향은 원시 오분류 개수만으로 판단하지 않고 클래스별 비율로 읽어야 한다. 이 결과는 공유 gradient 충돌의 제거 또는 EER 인과관계를 입증하지 않는다.
